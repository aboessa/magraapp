# إلزامية Character Sheet قبل الإنتاج المرئي

هذه قاعدة بوابة إلزامية، وليست اقتراحًا.

عند تصميم أو توليد **فيديو، أو صورة، أو سلسلة صور، أو قصة قصيرة/مصورة** تحتوي على شخصية بشرية أو حيوانية أو خيالية أو mascot:

1. أنشئ Character Sheet مستقلة لكل شخصية رئيسية أو متكررة **قبل** إنتاج أي لقطة أو صفحة أو غلاف نهائي.
2. يجب أن تعرض الشيت، بحسب ما يلائم الشخصية:
   - أمامي، جانبي، وخلفي أو ثلاثة أرباع.
   - تعبيرات الوجه الأساسية.
   - النِّسب والطول والحجم النسبي بين الشخصيات.
   - الملابس والإكسسوارات ولوحة الألوان الثابتة.
   - العلامات المميزة التي لا يجوز أن تتغير.
   - Props أو ألعاب متكررة إذا كانت جزءًا من هوية العمل.
3. اعرض Character Sheet على المستخدم وانتظر **اعتمادًا صريحًا**. لا تبدأ الصور أو الفيديو أو صفحات القصة النهائية قبل الاعتماد.
4. بعد الاعتماد، اعتبر الشيت المرجع البصري الأعلى للشخصية في كل Prompt وكل مراجعة، وثبّت وصفًا نصيًا مطابقًا لها في جميع المشاهد.
5. لا تفترض أن image-to-image أو seed يضمن الاتساق. اختبر قدرة المزوّد على تغيير المشهد مع الحفاظ على الهوية في لقطة أو لقطتين غير نهائيتين أولًا.
6. إذا كان مسار المرجع لدى المزوّد ينسخ التكوين، يتجاهل الـPrompt، أو يغيّر الهوية، أوقف الدفعة ولا تستهلك بقية الرصيد. استخدم بديلًا معتمدًا مثل Character/LoRA feature موثوقة أو قفل نصي صارم مع مراجعة بشرية وإعادة انتقائية.
7. راجع كل لقطة مقابل الشيت: الوجه، الشعر/الغطاء، لون البشرة/الفرو، الملابس، النِّسب، العمر الظاهر، الإكسسوارات، والـProps. أي اختلاف جوهري يُرفض ويُعاد توليده منفردًا.
8. أي تغيير جوهري لاحق في تصميم الشخصية يتطلب تحديث Character Sheet والحصول على اعتماد جديد قبل متابعة الإنتاج.
9. الصور التي لا تحتوي شخصيات، مثل خلفية مجردة أو object-only asset، لا تتطلب Character Sheet ما لم يكن العنصر نفسه شخصية أو mascot متكررًا.
10. لا تُدخل الشيت الخام أو صور المزوّد الخام إلى أصول الإنتاج. احتفظ بالمصدر في مسار العمل المخصص، وأدخل فقط مشتقات الإنتاج المراجعة والمحولة للصيغة المعتمدة.

## ترتيب العمل الإلزامي

`مواصفات الشخصية → Character Sheet → اعتماد المستخدم → اختبار اتساق محدود → إنتاج الدفعة → مراجعة لقطة بلقطة → ربط الإنتاج`
