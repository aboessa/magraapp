# تدفق المستخدم - الاستوديو الإبداعي

## 1. لون (المرحلة 1 - PNG)

### الطفل
```
الرئيسية (استوديو) -> [لون] -> Hero "هيا نلوّن!" + [ابدأ التلوين]
  -> شبكة "رسومات مميزة" (Grid 2x) [8 رسومات: عصفور صغير/قطة/ديناصور/سمكة...] كل كارت: صورة PNG شفافة + شارة "جديد" + نجمة
  -> شبكة "اختر رسمة لتلوينها" (فئات 8: طيور/حيوانات/مركبات/فضاء/زهور/بحرية/فواكه/ألعاب) كل فئة: gradient + أيقونة + عدد
  -> ضغط على رسمة مميزة -> لوحة التلوين "لوّن العصفور" (سكرين 5):
     - AppBar: رجوع + "لوّن العصفور" + مساعدة
     - قماش أبيض rounded 22 + صورة PNG خطية سوداء
     - badge "3 من 8 مناطق"
     - لوحة ألوان أفقية 8 ألوان (أزرق/أسود/أحمر...)
     - أزرار: حفظ/تلميح/من جديد/إعادة/تراجع
     - زر "تم" بنفسجي
     - شريط "رسومات أخرى" thumbnails
  -> ضغط على فئة (مثلا حيوانات) -> صفحة CategoryInside: فلترة عمر/صعوبة + Grid كل حيوانات
  -> رسم + حفظ -> Snackbar "تم الحفظ" + يظهر في "لوحاتي"
```

### الادمن (المرحلة 1)
```
لوحة تحكم -> استوديو الإبداع -> تبويب [تلوين]
  -> جدول 12 صف: صورة thumb + id + عنوان عربي + فئة فرعية + حالة + مميز/جديد + ترتيب
  -> زر "رسمة جديدة" -> نموذج: عنوان عربي * / فرعية (birds...) / صعوبة / عمر 3-12 / حالة / ترتيب / تاغز / باليت
  -> حفظ -> رفع PNG: زر "⬆️ PNG" يختار ملف PNG من assets/images/coloring/v2/bird.png -> يرفع إلى R2 `public/studio/coloring/bird.png` -> يظهر فوراً في التطبيق
  -> زر "✨ شفافة" -> يرفع النسخة الشفافة بعد remove-background (أو يطلب من السيرفر يعمله)
  -> تبديل "مميز ⭐" يظهرها في "رسومات مميزة"
  -> سحب وإفلات لإعادة الترتيب
```

## 2. ارسم مثلي (المرحلة 2 - صورة كاملة)

### الطفل
```
استوديو -> [ارسم مثلي] أو من "لوحاتي" تبويب "ارسم مثلي"
  -> Grid رسومات كاملة ملونة (مثل سكرين 1: منزل جميل/رحلة الفضاء/سلحفاة/باندا/زخرفة/سيارة) كل كارت: صورة كاملة + عنوان + وقت "منذ 6:45م"
  -> ضغط -> شاشة الرسم: نصفين: يمين مرجع ملون ثابت + يسار قماش فارغ للنسخ + أدوات (قلم/فرشاة/ممحاة) + لوحة ألوان
  -> حفظ -> يذهب لـ "لوحاتي"
```

### الادمن
```
تبويب [ارسم مثلي] -> جدول: صورة كاملة + عنوان + حالة
  -> رفع: PNG/JPG ملون كامل (بدون إزالة خلفية) -> R2 `public/studio/draw_like_me/{id}.png`
  -> لا حاجة لـ transparent
```

## 3. وصل النقاط (المرحلة 3)

### الطفل
```
تتبع وتعلم -> [وصل النقاط] أو استوديو -> وصل
  -> Grid نقاط: "خط مستقيم / دوائر / أرقام 1-5 / حرف أ" (سكرين 2)
  -> ضغط -> لوحة وصل (سكرين 6): نجمة 12 نقطة مرقمة، خط أزرق يتتبع، أزرار تلميح/إعادة/تراجع/تم + أنشطة مشابهة أسفل
```

### الادمن
```
تبويب [وصل النقاط] -> إنشاء: عنوان + صعوبة + نقاط JSON {dots:[{x,y,order}]} + صورة خلفية اختيارية
  -> رفع PNG للنقاط -> R2 `public/studio/connect_dots/{id}.png`
```

## 4. أكمل الرسمة (المرحلة 4)

### الطفل
```
استوديو -> [أكمل الرسمة]
  -> Grid: فراشة ناقصة / وجه / قلعة...
  -> ضغط -> لوحة أكمل (سكرين 7): يسار نصف ملون، يمين نصف منقط، أدوات قلم/فرشاة/ممحاة + ألوان + تم + حفظ رسمتي
```

### الادمن
```
تبويب [أكمل الرسمة] -> صورتين: PNG نصف مكتمل + PNG مكتمل للمرجع -> R2 `public/studio/complete/{id}.png` و `{id}-full.png`
  -> geometry: خط المنتصف
```

## 5. لوحاتي / My Boards (مشترك)
```
استوديو -> [لوحاتي] (سكرين 1)
  -> تبويبات: الكل/ارسم مثلي/ارسم بحرية + فلترة الأحدث
  -> Grid: صورة مصغرة + عنوان + "آخر تعديل 10:3 من / ارسم مثلي" + زر متابعة
  -> ضغط -> تفاصيل/حفظ كصورة/مشاركة/حذف
  -> زر "لوحة جديدة" + شريط "المساحة المستخدمة 12.4 من 100 ميجابايت" + "رفع المساحة"
```

## 6. تتبع وتعلم (موجود - يحتاج ربط R2)
```
تتبع وتعلم -> Hero + 4 كروت: الخطوط/الأشكال/الأرقام/الحروف (سكرين 2)
  -> اختر نشاط -> مستويات (مبتدئ/متوسط) -> لوحة تتبع مع تلميح وتراجع
  -> حفظ -> نجوم + تقدم
```
