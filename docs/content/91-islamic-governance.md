# 91 — الحوكمة الشرعية لكوكب الإيمان والآداب

ينطبق على كوكب `islamic` فقط. الكوكب حاليًا **8 سلاسل بصفر حلقات**، ومحجوب ببوابة اعتماد لم تُفتح.

## بوابة Phase 0 — إلزامية قبل أي إنتاج

| # | المتطلب | الحالة |
|---:|---|---|
| 1 | اختيار المرجع/الجهة الشرعية المؤهلة **لسوق الإطلاق** | ❌ |
| 2 | تعيين مراجع شرعي مؤهل | ❌ |
| 3 | تعيين مدقق عربي/قرآني مستقل | ❌ |
| 4 | مسار اعتماد موثق **ذو نسخة** | ❌ |
| 5 | ترخيص تلاوة مسجّلة | ❌ |

> **لا يجوز البدء بالإنتاج قبل اكتمال 1–5.** ولا يعني وجود هذه الوثيقة أن اعتمادًا قد حصل.

## المصادر المعتمدة

| النوع | الشرط |
|---|---|
| القرآن | نص **مصحف رسمي** |
| التفسير | **تفسير ميسر معتمد** |
| الحديث | بالمصدر والرقم و**الدرجة** |
| السيرة | **محققة** |
| التلاوة | تسجيل **مرخّص ومراجَع** |

## الممنوعات

| الممنوع | السبب |
|---|---|
| الفتاوى الشخصية | ليست وظيفة منصة أطفال |
| الخلاف المذهبي | يقسّم الجمهور ويُربك الطفل |
| التجريح | مخالف لقيم المنصة |
| السياسة والحزبية | خارج النطاق |
| العبادات الخلافية | تقتصر المادة على **الأصول المتفق عليها** |
| «تقييم إيماني» للطفل | لا يُستنتج التدين من سلوك تطبيق |
| streaks أو لوم | خصوصًا في المواسم |

## القيود البصرية — حاسمة

🚫 **يمنع تجسيد:**

- الله سبحانه وتعالى
- الأنبياء والرسل
- الملائكة
- الجن
- الغيب

**بما في ذلك الظلال والأجسام النورانية الموحية.** الإيحاء ممنوع كالتجسيد.

✅ **المسموح للقصص:** تصوير **المكان والطبيعة والعمارة والأشياء وآثار الحدث**، مع **راوٍ فقط**.

🚫 **لا تولّد الصور:** آيات، أحاديث، أدعية، أسماء مقدسة، أو خطًا عربيًا.
✅ **النص طبقة UI موثقة**، والتلاوة **تسجيل مرخص ومراجع**.

هذه القاعدة تتفق مع القاعدة العامة في [مواصفة الألعاب](../games/07-assets-and-brand.md): **لا نص مكتوب داخل أي صورة**.

## الحقول الشرطية الإلزامية

يمنع CMS النشر عند نقص أي منها لمحتوى `islamic`:

| الحقل | الغرض |
|---|---|
| `source_type` | نوع المصدر |
| `source_reference` | المرجع الكامل |
| `verse_surah` | السورة |
| `verse_ayah` | الآية |
| `hadith_collection` | مصدر الحديث |
| `hadith_number` | رقم الحديث |
| `hadith_grade` | درجة الحديث |
| `religious_reviewer_id` | المراجع الشرعي |
| `religious_review_version` | نسخة المراجعة |
| `religious_approved_at` | تاريخ الاعتماد |
| `visual_restrictions` | القيود البصرية للأصل |

## حالة العمل الإضافية

```
draft → writing → review_edu → review_lang → review_sharia → production → qa → ready → scheduled → published
```

`review_sharia` **إلزامية لهذا الكوكب فقط**، وموجودة في مخطط `series.status` و`episodes.status` لكنها **غير مُختبرة عمليًا** بعد.

## تحكم ولي الأمر

| المتطلب | التفصيل |
|---|---|
| تحكم مستقل | ولي الأمر يتحكم في **العالم** وفي **كل رف** على حدة |
| احترام التوصيات | نظام التوصية يحترم هذا السماح ولا يتجاوزه |
| القياس | يقتصر على **الاستماع والفهم وإكمال النشاط** |
| ممنوع | استنتاج التدين أو عرض «تقييم إيماني» |
| المواسم | بلا streaks ولا لوم على الغياب |

## QA الخاص

| الفحص | المعيار |
|---|---|
| المرجع | موجود وموثق ومطابق للنسخة |
| المصدر | كامل بالرقم والدرجة |
| النص | مطابق للمصحف الرسمي حرفًا |
| التلاوة | مرخّصة ومراجَعة |
| منع النشر | يعمل فعلًا عند نقص أي حقل شرطي |
| القيود البصرية | لا تجسيد ولا إيحاء في أي أصل |
| اللغة | مدقق عربي/قرآني مستقل أقرّها |

## ملاحظة على المسؤولية

الخطأ في هذا الكوكب **لا يُعالج بتحديث**. المحتوى الديني الخاطئ الذي وصل طفلًا يترك أثرًا لا يُلغى بإصدار جديد، ويعرّض المنصة لمساءلة تحريرية ومجتمعية وقانونية.

لذلك: **البوابة أولًا، ثم الإنتاج.**
