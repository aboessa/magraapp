`family_activity_ar`:
> **سؤال يفرّق.** اطرحوا معًا أسئلة بسيطة عن أشياء في البيت: «هل يسمع؟ هل ينفع؟ هل يضر؟» ليتعلّم الطفل أن السؤال الهادئ يميّز الحق. بلا كسر ولا خطر.

## القيود البصرية

- ساحة قديمة وتماثيل حجرية مكسورة وأدوات ساكنة ونار بعيدة تخمد، وأثر سلام.
- **ممنوع تجسيد الله أو إبراهيم أو أي نبي أو رسول أو ملَك أو جنّ أو الغيب**، ولو بوجه أو جسد أو طرف أو ظلّ أو جسم نوراني أو صوت منسوب أو مكان فارغ يلمّح إلى حضور. لا تُرسم المعجزة ولا جسد داخل النار؛ نعتمد أثر الحدث لا تجسيده.
- **ممنوع أي شعار أو علامة مائية أو نص أو حروف أو علامة تجارية أو caption أو branding أو واجهة UI أو overlay** داخل الصورة. النص كله طبقة UI من ملفات الترجمة.
