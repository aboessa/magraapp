## القيود البصرية

- بئر قديم وغنم ودلو وحبل وظل شجرة وآثار ماء بعد الحدث.
- **ممنوع تجسيد الله أو موسى أو أي نبي أو رسول أو ملَك أو جنّ أو الغيب**، ولو بوجه أو جسد أو طرف أو ظلّ أو جسم نوراني أو صوت منسوب أو موضع كاميرا ينتظره أو مكان فارغ يلمّح إلى حضور. نعتمد أثر الحدث لا تجسيده.
- **ممنوع أي شعار أو علامة مائية أو نص أو حروف أو علامة تجارية أو caption أو branding أو واجهة UI أو overlay** داخل الصورة. النص كله طبقة UI من ملفات الترجمة.

## القيود الصوتية

- لا صوت منسوب إلى نبي أو ملَك أو الغيب.
- صوت راوٍ (لونا) فقط، ومؤثرات بيئية هادئة.
- بلا تهويل صوتي ولا مؤثرات رعب.
- لا موسيقى تصعّد الحدث دراميًا.
