# دليل السلسلة — جرّب في البيت

`Series Bible` · `presenter` · 6–8 · **`supervision_level = required`** · الإصدار 1.0

> 🔴 **هذه أخطر سلسلة في المنصة.** الطفل ينفّذ نشاطًا حقيقيًا بأدوات منزلية. الخطأ هنا لا يُصحَّح بتحديث.

---

## 1. الفكرة في جملة

يقدّم **أستاذ كريم** تجربة منزلية واحدة في كل حلقة، بأدوات آمنة موجودة في كل بيت، **ويشرك ولي الأمر صريحًا** في كل خطوة.

## 2. بروتوكول السلامة — الأهم في هذا الدليل

### القواعد المطلقة

| # | القاعدة |
|---:|---|
| 1 | **لا نار · لا حرارة · لا كهرباء · لا مواد كيميائية · لا أدوات حادة** |
| 2 | **لا شيء يُشرب أو يُؤكل** أثناء التجربة، ولو كان طعامًا |
| 3 | **لا قطعة صغيرة** يمكن استنشاقها أو بلعها لطفل أصغر في البيت |
| 4 | **لا زجاج.** كل الأوعية بلاستيك أو معدن |
| 5 | كل حلقة تبدأ بـ**دعوة ولي الأمر صريحة** وتُعاد قبل التنفيذ |
| 6 | `safety_notes` **غير فارغة** إلزاميًا في قاعدة البيانات |
| 7 | مراجعة **مراجع سلامة معتمد** موثقة قبل النشر |

### ما يُذكر في كل حلقة

| المقطع | المحتوى |
|---|---|
| الأدوات | قائمة كاملة **قبل** البدء، بلا استثناء |
| الدعوة | «نادِ أمك أو أباك ليجرّب معك» |
| التحذير | ما لا يُفعل، بصيغة **إيجابية** لا مخيفة |
| التنظيف | خطوة أخيرة إلزامية |

### صيغة التحذير

| ✅ صحيح | ❌ خطأ |
|---|---|
| «الماء للتجربة فقط، لا للشرب.» | «احذر! الماء خطير!» |
| «اطلب من أمك أن تسكب الماء.» | «لا تلمس الماء وحدك!» |
| «نجفّف الطاولة معًا بعد التجربة.» | «ستوسّخ البيت!» |

**المبدأ:** التحذير يُوجّه للفعل الصحيح، لا يُخيف من الفعل الخطأ. الخوف يُنتج طفلًا يتجنّب التجربة، والتوجيه يُنتج طفلًا يجرّب بأمان.

## 3. المقدّم — أستاذ كريم

| الحقل | القيمة |
|---|---|
| النوع | **شخصية مرسومة** لا ممثل حقيقي |
| العمر الظاهري | رجل ثلاثيني |
| الشكل | عربي، لحية قصيرة مرتّبة، معطف مختبر `#F2F6FF` |
| الموضع | يمين الكادر *(يسار في LTR)* |
| النبرة | هادئة، واثقة، **حذرة بلا توتر** |
| ما يفعله | يُري الخطوة بيديه · يعدّ الأدوات · ينتظر |
| ما لا يفعله | لا يستعجل · لا يبالغ في الإثارة · **لا يعِد بنتيجة مذهلة** |

### لماذا مرسوم لا حقيقي

| السبب | التفصيل |
|---|---|
| السلامة | لا مشاهد تصوير حقيقية يقلّدها الطفل حرفيًا بأدوات مختلفة |
| الاتساق | نفس المعطف والمختبر في كل حلقة |
| الترجمة | تبديل الصوت لأي لغة بلا إعادة تصوير |
| التكلفة | لا موقع ولا إعادة تصوير عند تعديل خطوة |

**لكن:** `production_level = live` في قاعدة البيانات يعني **تصوير حقيقي للتجربة نفسها** (اليدان والأدوات)، مع مقدّم مرسوم يشرح. مزيج مقصود: الطفل يرى التجربة الحقيقية، والمقدّم ثابت مرسوم.

## 4. بنية الحلقة الثابتة

| المقطع | المدة | المحتوى |
|---|---:|---|
| افتتاحية | 0:00–0:15 | شعار + كريم يرحّب |
| **دعوة ولي الأمر** | 0:15–0:35 | «نادِ أمك أو أباك» — إلزامية |
| الأدوات | 0:35–1:00 | قائمة كاملة + ملاحظة سلامة |
| السؤال | 1:00–1:25 | ماذا سيحدث؟ **توقّع** |
| الخطوات | 1:25–2:55 | خطوة خطوة، بطيئة |
| الملاحظة | 2:55–3:35 | ماذا حدث فعلًا؟ |
| التفسير | 3:35–4:10 | لماذا حدث؟ |
| التنظيف والخاتمة | 4:10–4:30 | تنظيف + دعوة للعبة |

**المدة: 4:30 دقيقة.**

**ملاحظة على البنية:** التوقّع **قبل** التنفيذ إلزامي — هذا يجعلها تجربة علمية لا عرضًا. والتنظيف **جزء من التجربة** لا إضافة.

## 5. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `live` — تصوير حقيقي للتجربة + مقدّم مرسوم |
| زاوية التصوير | **من أعلى** للطاولة — يرى الطفل كما لو كان يفعلها |
| الإضاءة | ساطعة متساوية، بلا ظلال حادة |
| الأدوات | **بلاستيك ملوّن واضح**، لا زجاج |
| السرعة | خطوة كل 8–12 ثانية · **لا تسريع** |
| القطع | لا قطع في منتصف خطوة — الخطوة كاملة في لقطة واحدة |

**قاعدة تصوير حاسمة:** **لا تسريع (`time-lapse`) لأي خطوة تنفيذية.** الطفل يجب أن يرى الزمن الحقيقي ليعرف كم تأخذ. التسريع مسموح **فقط** لنتيجة تحتاج ساعات (نمو البذرة)، ومع تنبيه صريح.

## 6. الألوان

| الاستخدام | اللون |
|---|---|
| خلفية المختبر | `#101735` |
| الطاولة | `#1B236B` |
| معطف كريم | `#F2F6FF` |
| تحديد وإشارة | `#00D6F5` |
| **ملاحظة سلامة** | `#FF9F1C` |
| نتيجة/نجاح | `#FFD34D` |

**`#FF9F1C` مخصّص لملاحظات السلامة** في هذه السلسلة، ولا يُستخدم لغيرها. لا أحمر — الأحمر يُخيف.

## 7. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 12 كلمة** |
| السرعة | ~110 كلمة/دقيقة — أبطأ من سلاسل `kids` الأخرى |
| الوقفة بين الخطوات | **1.5 ثانية** — يحتاج الطفل زمنًا للتنفيذ |
| بعد سؤال التوقّع | **صمت 5 ثوان** |
| الأدوات | كل أداة تُسمّى **مرتين** |

### بنك عبارات كريم

**دعوة:** نادِ أمك أو أباك · اطلب المساعدة · لنعمل معًا

**توقّع:** ماذا تتوقّع؟ · خمّن قبل أن نجرّب · ما رأيك؟

**سلامة:** الماء للتجربة فقط · اطلب من أمك أن تسكب · نجفّف معًا بعد قليل

**تشجيع:** ملاحظة دقيقة! · لاحظت الفرق، ممتاز · **توقّعك جزء من العلم**

**ممنوع في بنكه:** «مذهل!» · «لا تصدّق!» · «سحر!» · أي وعد بنتيجة مثيرة.

> **قاعدة:** العلم ليس سحرًا. وصف التجربة بـ«سحر» يعلّم الطفل أن ما لا يفهمه سحر — عكس هدف السلسلة تمامًا.

## 8. الصوت

| الحقل | القيمة |
|---|---|
| صوت كريم | معلّق عربي، نبرة **هادئة واثقة** غير متحمسة مصطنعة |
| السرعة | ~110 كلمة/دقيقة |
| الموسيقى | خفيفة جدًا أو **بلا موسيقى** أثناء الخطوات |
| أصوات التجربة | **حقيقية** — سكب الماء، لصق الشريط |
| المؤثرات | ≤ 400ms · لا أصوات مفاجئة |

**قرار صوتي:** الموسيقى **تتوقف** أثناء الخطوات التنفيذية. الطفل يحتاج تركيزًا، والصوت الحقيقي للتجربة أهم من اللحن.

## 9. `safety_notes` — القالب الإلزامي

كل حلقة تحمل في قاعدة البيانات:

```
الأدوات: [قائمة كاملة]
الإشراف: مطلوب — ولي الأمر يحضر التجربة كاملة.
تحذيرات: [ما لا يُفعل، بصيغة إيجابية]
غير مناسب إذا: [وجود طفل أصغر من 3 سنوات في الغرفة / حساسية معروفة]
التنظيف: [خطوات]
```

**حقل فارغ = منع نشر.** CMS يرفض.

## 10. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| الأدوات | **تُراجع لكل سوق** — بعض الأدوات غير متوفرة في كل بلد |
| ملاحظات السلامة | **تُراجع قانونيًا لكل سوق** لا تُترجم آليًا |
| وحدات القياس | متري، ويُضاف بديل حسب السوق |

> ⚠️ **تنبيه ترجمة:** ملاحظات السلامة **مسؤولية قانونية**. لا تُترجم آليًا، وتُراجع في كل سوق بمعرفة متطلباته.

## 12. معايير قبول الحلقة

- [ ] المدة 4:30 ±15 ثانية.
- [ ] كل جملة ≤ 12 كلمة.
- [ ] **دعوة ولي الأمر** في مقطع مستقل، وتُعاد قبل التنفيذ.
- [ ] الأدوات تُعرض **كاملة قبل** البدء، وكل أداة تُسمّى مرتين.
- [ ] **لا نار · لا حرارة · لا كهرباء · لا كيمياء · لا حاد · لا زجاج.**
- [ ] لا شيء يُشرب أو يُؤكل.
- [ ] لا قطعة صغيرة قابلة للبلع.
- [ ] التحذيرات بصيغة **إيجابية** لا مخيفة.
- [ ] **التوقّع قبل التنفيذ** موجود، مع صمت 5 ثوان.
- [ ] خطوة كل 8–12 ثانية، وقفة 1.5s بينها.
- [ ] **لا تسريع** لأي خطوة تنفيذية.
- [ ] الموسيقى تتوقف أثناء الخطوات.
- [ ] **التنظيف** مقطع إلزامي.
- [ ] `safety_notes` مكتملة بالقالب الكامل.
- [ ] كلمة «سحر» أو «مذهل» **غير موجودة**.
- [ ] 🔴 **مراجعة مراجع سلامة معتمد** موثقة.
- [ ] 🔴 **مراجعة مراجع علمي معتمد** موثقة.
- [ ] لا وميض > 3Hz · لا صوت مفاجئ.
