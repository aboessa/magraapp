# دليل السلسلة — اكتشف جسمك

`Series Bible` · `knowledge` · 6–8 · الإصدار 1.0

> 🔴 **تحتاج مراجعًا طبيًا للأطفال** إضافة إلى المراجع العلمي. المعلومة الطبية الخاطئة أخطر من غيرها.

---

## 1. الفكرة في جملة

رحلة داخل جسم الإنسان بأسلوب `stylized_3d` مبسّط، تُقدَّم بصوت راوٍ بلا شخصية ثابتة، وتجيب في كل حلقة عن سؤال واحد يسأله الأطفال فعلًا.

## 2. لماذا `knowledge` بلا شخصية

| السبب | التفصيل |
|---|---|
| المحتوى هو البطل | الجسم نفسه هو ما نستكشفه، وشخصية إضافية تشتّت |
| المرونة | إضافة حلقة لا تحتاج استمرارية قصصية |
| الحياد | لا يرتبط الجسم بشخصية معيّنة — كل طفل يرى **جسمه هو** |
| التكلفة | لا دليل شخصية ولا تحريك شخصي |

**الراوي** صوت فقط: هادئ، ودّي، **لا يظهر بصريًا**.

## 3. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `stylized_3d` — الأعلى تكلفة في المنصة |
| الأسلوب | **مبسّط رمزي لا تشريحي واقعي** |
| الألوان | من هوية مجرة، لا ألوان طبية واقعية |
| الجسم | شكل طفل محيّد: بلا تحديد جنس واضح، بلا لون بشرة محدد |
| العضو المشروح | يتوهّج `#00D6F5` ويُعزل عن الباقي |

### 🔴 حدود التصوير الطبي — إلزامية

| ❌ ممنوع تمامًا | السبب |
|---|---|
| دم أو سوائل جسدية | مخيف لهذا العمر |
| تشريح واقعي أو صور حقيقية | مخيف ومقزّز |
| عضو مفتوح أو مقطوع | صادم |
| إبر أو جراحة أو مستشفى | يربط الجسم بالخوف |
| مرض أو ألم مُصوَّر | قلق صحي غير ضروري |
| ملمس عضوي واقعي (لزج، لامع) | مقزّز |

| ✅ مسموح | الشكل |
|---|---|
| العضو | شكل هندسي مبسّط بلون واحد |
| الحركة | تدفّق رمزي بأسهم أو نقاط متحركة |
| الصوت | نبضة قلب هادئة، تنفّس خفيف |
| المقارنة | «القلب بحجم قبضة يدك» |

**المبدأ:** الطفل يخرج من الحلقة **معجبًا بجسمه لا خائفًا منه**.

## 4. قاعدة التبسيط بلا تحريف

| ✅ صحيح | ❌ خطأ |
|---|---|
| «القلب يدفع الدم إلى كل الجسم.» | «القلب يصنع الدم.» |
| «الرئتان تأخذان الهواء.» | «الرئتان تصنعان الهواء.» |
| «العظام تحمل جسمك.» | «العظام تنمو كل يوم كثيرًا.» |

**التبسيط يحذف تفاصيل، لا يقلب حقائق.** أي جملة تُبسّط بطريقة تخلق مفهومًا خاطئًا يصعب تصحيحه لاحقًا **مرفوضة**.

## 5. أسئلة يسألها الأطفال فعلًا

كل حلقة تجيب عن سؤال حقيقي:

| الحلقة | السؤال |
|---|---|
| القلب | لماذا أسمع دقات في صدري؟ |
| الحواس | كيف أعرف أن الطعام حلو؟ |
| التنفس | لماذا أتنفّس أسرع بعد الجري؟ |
| العظام | لماذا لا أنثني في كل مكان؟ |
| الطعام | إلى أين يذهب طعامي؟ |
| النظافة | لماذا أغسل يدي؟ |

**هذا اختيار تحريري مقصود:** المحتوى يجيب عن فضول حقيقي لا عن منهج مدرسي.

## 6. بنية الحلقة الثابتة

| المقطع | المدة | المحتوى |
|---|---:|---|
| افتتاحية | 0:00–0:15 | شعار + السؤال يُطرح |
| السؤال | 0:15–0:45 | موقف يومي يثير السؤال |
| الاستكشاف | 0:45–2:15 | العضو ووظيفته، بالتوهّج والحركة |
| التجربة الذاتية | 2:15–3:00 | **الطفل يجرّب على جسمه** بأمان |
| الربط | 3:00–3:45 | لماذا يهمّني هذا؟ |
| التطبيق | 3:45–4:15 | سؤال فهم |
| الخاتمة | 4:15–4:30 | تلخيص + دعوة للعبة |

**المدة: 4:30 دقيقة.**

### التجربة الذاتية — إلزامية وآمنة

كل حلقة فيها لحظة يجرّب الطفل شيئًا **على جسمه**: يضع يده على صدره ليحسّ النبض · يغمض عينيه ويلمس · يعدّ أنفاسه.

| ✅ مسموح | ❌ ممنوع |
|---|---|
| لمس النبض على الصدر أو الرسغ | كتم النفس |
| عدّ الأنفاس | الجري حتى الإجهاد |
| إغماض العينين | الضغط على أي عضو |
| تحسّس العظام من الخارج | تذوّق أو شمّ مواد |

## 7. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | ≤ 12 كلمة |
| السرعة | ~120 كلمة/دقيقة |
| المصطلح العلمي | يُذكر **مرة** ثم يُشرح بكلمة مألوفة |
| بعد سؤال | صمت 4 ثوان |
| المقارنات | من عالم الطفل: «بحجم قبضة يدك» |

### المصطلحات — سياسة الاستخدام

| المصطلح | يُقدَّم كيف |
|---|---|
| القلب · الرئتان · العظام | أسماء مألوفة، تُستخدم مباشرة |
| النبض | «دقّة القلب التي تحسّها» |
| الأكسجين | «الهواء المفيد» ثم الاسم |
| الهضم | «كيف يستفيد جسمك من الطعام» |
| المفصل | «مكان الانثناء» ثم الاسم |

**قاعدة:** المصطلح **بعد** المعنى لا قبله. وكل مصطلح يُذكر مرتين على الأكثر في الحلقة.

## 8. الصوت

| الحقل | القيمة |
|---|---|
| الراوي | معلّق عربي، نبرة **ودّية هادئة غير درامية** |
| السرعة | ~120 كلمة/دقيقة |
| أصوات الجسم | نبضة قلب **هادئة منتظمة** ≤ 60 نبضة/دقيقة في العرض |
| الموسيقى | خفيفة، −18 dB |
| المؤثرات | ≤ 400ms · **لا أصوات عضوية مقزّزة** |

**تنبيه:** نبضة القلب المعروضة **أبطأ من الحقيقية** حتى لا تُقلق الطفل أو تُسرّع نبضه بالتقليد.

## 9. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| المصطلحات الطبية | **تُراجع طبيًا لكل لغة** لا تُترجم آليًا |
| الجسم المرسوم | محيّد — يعمل في كل الثقافات |
| المقارنات | «بحجم قبضة يدك» عالمية |

⚠️ المصطلحات الطبية تختلف بين المدارس اللغوية العربية نفسها. **يُثبَّت مصطلح واحد** لكل مفهوم في كل السلسلة.

## 11. معايير قبول الحلقة

- [ ] المدة 4:30 ±15 ثانية.
- [ ] كل جملة ≤ 12 كلمة.
- [ ] الحلقة تجيب عن **سؤال حقيقي** يسأله الأطفال.
- [ ] **التجربة الذاتية** موجودة وآمنة تمامًا.
- [ ] 🔴 **لا دم · لا تشريح واقعي · لا إبر · لا مرض · لا ملمس عضوي**.
- [ ] الجسم المرسوم **محيّد**: بلا جنس أو لون بشرة محدد.
- [ ] التبسيط **لا يقلب حقيقة**.
- [ ] المصطلح **بعد** المعنى، ومرتان كحد أقصى.
- [ ] نبضة القلب المعروضة **أبطأ من الحقيقية**.
- [ ] الطفل يخرج **معجبًا بجسمه لا خائفًا**.
- [ ] 🔴 **مراجعة مراجع طبي للأطفال** موثقة.
- [ ] 🔴 **مراجعة مراجع علمي** موثقة.
- [ ] مصطلح موحّد لكل مفهوم في السلسلة كلها.
- [ ] لا وميض > 3Hz · لا صوت مقزّز.
