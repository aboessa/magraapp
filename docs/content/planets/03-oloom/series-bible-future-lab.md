# دليل السلسلة — مختبر المستقبل

`Series Bible` · `knowledge` · 9–12 · الإصدار 1.0

---

## 1. الفكرة في جملة

تحدٍّ هندسي في كل حلقة: مشكلة حقيقية، وفرضية، ومحاكاة تُختبر فيها المتغيرات، ثم تفسير — بأسلوب يحترم عقل الروّاد ولا يخاطبهم كصغار.

## 2. المبدأ الحاكم: المنهج العلمي كاملًا

كل حلقة تمرّ بالمراحل الخمس **بلا استثناء**:

| المرحلة | ما يحدث |
|---:|---|
| 1. **المشكلة** | تحدٍّ هندسي واقعي |
| 2. **الفرضية** | توقّع مُعلَّل قبل التجربة |
| 3. **التجربة** | تغيير متغيّر واحد وتثبيت الباقي |
| 4. **البيانات** | جدول نتائج مرئي |
| 5. **التفسير** | استنتاج من البيانات لا من الحدس |

> **الفرضية الخاطئة ليست فشلًا.** تُسجَّل كتعلّم، و**التفسير** هو ما يُقاس. هذا القرار التربوي هو جوهر السلسلة.

### المتغيّر الواحد

قاعدة صارمة تُعلَّم صريحًا: **نغيّر متغيّرًا واحدًا ونثبّت الباقي.** بدونها لا تُنتج التجربة معرفة. تُذكر في كل حلقة.

## 3. النبرة — احترام الروّاد

| ✅ مسموح | ❌ ممنوع |
|---|---|
| «استنتاج صحيح.» | «يا بطل!» |
| «تحليل دقيق.» | «رائع! مذهل! خارق!» |
| «راجع العلاقة بين الصفين.» | «حاول مرة أخرى يا حبيبي» |
| «التجربة تسمح بالخطأ.» | تصغير أو تدليل |
| مصطلح علمي مشروح | تبسيط مُهين |

> **الروّاد يتركون التطبيق إذا خُوطبوا كأطفال صغار.** النبرة المحترمة ليست ترفًا بل شرط بقاء.

## 4. الراوي

| الحقل | القيمة |
|---|---|
| النوع | صوت فقط، **بلا شخصية بصرية** |
| النبرة | محترمة، واثقة، **غير درامية** |
| الدور | يطرح المشكلة، يوجّه، **لا يعطي الجواب** |
| ما لا يفعله | لا يبالغ · لا يمدح الذكاء · لا يستعجل |

**قرار:** بلا شخصية بصرية لأن **المحاكاة هي البطل**. شخصية إضافية تشتّت عن البيانات.

## 5. المحاكاة — قلب السلسلة

كل حلقة مبنية على محاكاة تفاعلية على محرك `sim_lab`:

| الحلقة | `sim` | المتغيّرات | العلاقة |
|---|---|---|---|
| المركبة الشمسية | `solar` | زاوية الضوء، الوزن | طردية ثم تشبّع |
| الجسر القوي | `bridge` | الشكل، الطول | شكلية |
| الدائرة الكهربية | `circuit` | البطاريات، المصابيح | طردية / عكسية |
| البندول | `pendulum` | الطول، الكتلة | **الطول يؤثر، الكتلة لا** |
| الروبوت المتوازن | `balance` | ارتفاع الحمل، القاعدة | عكسية |
| تجربتي أنا | حرّة | يختارها الطفل | يستنتجها |

**حلقة البندول الأهم تربويًا:** تعلّم أن **متغيّرًا قد لا يكون له تأثير**. مفهوم يصعب تعليمه بغير المحاكاة، والطفل الذي يفهمه يقاوم الاستنتاجات المتسرّعة.

**حلقة تجربتي أنا:** الطفل **يصمّم التجربة** — يختار ما يثبّت وما يغيّر. أعلى مستوى في السلسلة.

## 6. بنية الحلقة الثابتة

| المقطع | المدة | المحتوى |
|---|---:|---|
| افتتاحية | 0:00–0:20 | شعار + المشكلة تُطرح |
| المشكلة | 0:20–1:10 | تحدٍّ هندسي واقعي |
| الفرضية | 1:10–2:00 | توقّع مُعلَّل + صمت |
| التجربة الأولى | 2:00–3:00 | تغيير متغيّر واحد |
| البيانات | 3:00–4:00 | جدول نتائج، عدة محاولات |
| الاكتشاف | 4:00–5:00 | ما تكشفه البيانات |
| التفسير | 5:00–6:10 | لماذا؟ + خيارات تفسير |
| التطبيق | 6:10–6:45 | سؤال نقل لسياق جديد |
| الخاتمة | 6:45–7:00 | تلخيص المبدأ |

**المدة: 7:00 دقيقة** — الأطول في المنصة، ومناسبة لمدى انتباه 9–12.

## 7. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `stylized_3d` |
| الأسلوب | هندسي نظيف، **بلا زخرفة** |
| جدول البيانات | **مرئي دائمًا** أثناء التجربة |
| المتغيّر المتغيّر | يتوهّج `#00D6F5` |
| المتغيّر المثبّت | باهت `#AAB5D1` — يُبرز التثبيت بصريًا |
| النتيجة | `#FFD34D` |
| الرسم البياني | يُبنى نقطة نقطة مع كل محاولة |

**قاعدة بصرية محورية:** إبراز المتغيّر المتغيّر وإباهت المثبّت **يعلّم قاعدة المتغيّر الواحد بصريًا** بلا شرح لفظي متكرر.

## 8. جدول البيانات — إلزامي نصيًا

| المتطلب | التفصيل |
|---|---|
| الشكل | **جدول نصي** لا رسم بياني فقط |
| البناء | صف جديد مع كل محاولة |
| القراءة | كل قيمة تُنطق عند إضافتها |
| إمكانية الوصول | متاح لقارئ الشاشة |

**السبب:** الرسم البياني وحده يستبعد الطفل ضعيف البصر، ويخفي القيم الدقيقة. الجدول النصي أدقّ وأشمل.

## 9. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 20 كلمة** |
| السرعة | ~135 كلمة/دقيقة — طبيعية |
| المصطلح | يُستخدم مباشرة ثم يُشرح **مرة** |
| بعد سؤال الفرضية | **صمت 6 ثوان** — أطول في المنصة |
| بعد سؤال التفسير | صمت 6 ثوان |

### بنك عبارات الراوي

**نجاح:** استنتاج صحيح. · تحليل دقيق. · صحيح — لاحظت القاعدة. · حل فعّال.

**محاولة:** ليست صحيحة. راجع العلاقة. · أعد النظر في المتغيّر الذي تغيّر. · قارن الصف الأول بالأخير.

**فرضية خاطئة:** لنرَ ما تقوله البيانات. · فرضيتك قابلة للاختبار — وهذا ما يهم. · التجربة تسمح بالخطأ.

**ممنوع:** أي مدح للذكاء («أنت ذكي») — يُمدح **الجهد والتحليل** فقط.

## 10. الصوت

| الحقل | القيمة |
|---|---|
| الراوي | معلّق عربي، نبرة **محترمة غير طفولية** |
| السرعة | ~135 كلمة/دقيقة |
| القيم الرقمية | تُنطق عند إضافتها للجدول |
| الموسيقى | هادئة، **تتوقف** أثناء قراءة البيانات |
| المؤثرات | ≤ 400ms · نغمة إضافة صف للجدول |

## 11. السلامة

| البند | القاعدة |
|---|---|
| كل التجارب | **محاكاة رقمية** — لا تنفيذ منزلي |
| `supervision_level` | `recommended` لا `required` |
| حلقة الدائرة الكهربية | 🔴 **تحذير صريح**: «هذه محاكاة. لا تجرّب بكهرباء البيت.» |
| أي إشارة لأداة حقيقية | تُحذف أو تُحوّل لمحاكاة |

> ⚠️ **حلقة الدائرة الكهربية تحتاج مراجعة سلامة خاصة.** الطفل قد يحاول التقليد بكهرباء حقيقية. التحذير إلزامي ويُعاد.

## 12. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| المحاكاة | **`language_neutral`** — الفيزياء عالمية |

| الأرقام | `numeral_system: auto` |
| المصطلحات العلمية | تُراجع علميًا لكل لغة |

## 14. معايير قبول الحلقة

- [ ] المدة 7:00 ±20 ثانية.
- [ ] كل جملة ≤ 20 كلمة.
- [ ] **المراحل الخمس كاملة**: مشكلة، فرضية، تجربة، بيانات، تفسير.
- [ ] **الفرضية قبل التجربة**، وصمت 6 ثوان.
- [ ] الفرضية الخاطئة **لا تُخصم ولا تُوصف بالفشل**.
- [ ] `score` من **التفسير** فقط.
- [ ] قاعدة **المتغيّر الواحد** مُعلَّمة صريحًا.
- [ ] المتغيّر المتغيّر يتوهّج، والمثبّت **يبهت**.
- [ ] **جدول بيانات نصي** متاح لقارئ الشاشة.
- [ ] ≥ 3 محاولات قبل السماح بالتفسير.
- [ ] النبرة **محترمة غير طفولية** — لا تصغير.
- [ ] **لا مدح للذكاء** — الجهد والتحليل فقط.
- [ ] أزرار +/− بديلة للمنزلق.
- [ ] 🔴 حلقة الكهرباء: تحذير «محاكاة لا تُجرَّب» إلزامي ويُعاد.
- [ ] 🔴 **مراجعة مراجع علمي** موثقة.
- [ ] 🔴 **مراجعة مراجع سلامة** لحلقة الكهرباء.
- [ ] لا وميض > 3Hz.
