# دليل السلسلة — علوم في دقيقة

`Series Bible` · `presenter` · 9–12 · `motion_story` · الإصدار 1.0

> 💡 **أرخص سلسلة إنتاجًا في المنصة، وأسرعها توسّعًا.** مناسبة لزيادة كثافة الكتالوج بسرعة وتكلفة منخفضة.

---

## 1. الفكرة في جملة

تفسير علمي **مركّز في دقيقتين** لظاهرة يراها الطفل في حياته، بلا حشو ولا تمهيد.

## 2. المدة: 2:00 دقيقة — قرار مقصود

| السبب | التفصيل |
|---|---|
| القابلية للمشاهدة | يُشاهد في أي وقت قصير، بلا التزام |
| التكلفة | `motion_story` — صور ثابتة وحركة كاميرا |
| السرعة | يمكن إنتاج 6 حلقات بتكلفة حلقة `stylized_3d` واحدة |
| التوسّع | إضافة موضوع جديد رخيصة |
| التركيز | مفهوم واحد فقط، بلا تشتّت |

**قاعدة صارمة: مفهوم واحد لكل حلقة.** الدقيقتان لا تتحمّل أكثر، ومحاولة الحشو تُفسد الغرض.

## 3. البنية الثابتة — دقيقتان بالثانية

| المقطع | المدة | المحتوى |
|---|---:|---|
| السؤال | 0:00–0:15 | ظاهرة يومية + السؤال مباشرة |
| الملاحظة | 0:15–0:40 | ما نراه بالضبط |
| التفسير | 0:40–1:20 | لماذا يحدث |
| التطبيق | 1:20–1:45 | أين نراه أيضًا |
| الخاتمة | 1:45–2:00 | جملة تُحفظ |

**لا افتتاحية طويلة.** الشعار 3 ثوان فقط ثم السؤال مباشرة. الافتتاحية الطويلة تستهلك ربع الحلقة.

## 4. جملة الختام — العنصر المميّز

كل حلقة تنتهي بجملة واحدة **قابلة للحفظ والنقل**:

| الحلقة | جملة الختام |
|---|---|
| انكسار الضوء | «الضوء يتغيّر مساره عند تغيّر الوسط.» |
| ضغط الهواء | «الهواء يدفع في كل الاتجاهات.» |
| أطوار القمر | «القمر لا يتغيّر، بل ما نراه منه.» |
| من أين الكهرباء؟ | «الكهرباء لا تُصنع، بل تُحوَّل.» |
| دورة الماء | «الماء لا يفنى، بل يتحرّك.» |
| لماذا ننام؟ | «النوم ليس توقّفًا، بل عمل داخلي.» |

**التصميم:** الجملة تُنطق ببطء، وتُعرض بصريًا، وتُعاد صوتيًا. هذه هي **الحصيلة القابلة للتذكّر** بعد أسبوع.

## 5. المقدّمة — ليلى

| الحقل | القيمة |
|---|---|
| النوع | **شخصية مرسومة** ثابتة |
| العمر الظاهري | شابة عشرينية |
| الشكل | عربية، شعر قصير، سترة `#45B7D1` |
| الموضع | زاوية الكادر، **صغيرة** — لا تنافس المحتوى |
| النبرة | واضحة، سريعة قليلًا، **واثقة غير متحمسة** |
| الدور | تسأل وتفسّر، **لا تمثّل** |

**قرار:** ليلى **صغيرة في الكادر** لأن المحتوى البصري للظاهرة هو البطل في سلسلة قصيرة كهذه.

## 6. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `motion_story` — الأرخص |
| التقنية | صور ثابتة عالية الجودة + حركة كاميرا + طبقات بسيطة |
| عدد اللقطات | **5–7 فقط** |
| الرسوم التوضيحية | مخطط واحد واضح لكل حلقة |
| النص على الشاشة | جملة الختام **فقط**، من ملفات الترجمة |
| الألوان | `#45B7D1` أساسي + هوية مجرة |

**كيف تُنتج بتكلفة منخفضة:** لقطة واحدة لكل مقطع بنيوي، مع حركة كاميرا بطيئة (`Ken Burns`) وطبقتين أو ثلاث متحركة. لا تحريك شخصيات ولا 3D.

## 7. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | ≤ 20 كلمة |
| السرعة | ~140 كلمة/دقيقة — الأسرع في المنصة |
| عدد الجمل | **18–22 جملة** لكل حلقة |
| الوقفات | قصيرة 400ms — الكثافة عالية |
| بعد سؤال | **صمت 3 ثوان** فقط |
| جملة الختام | تُنطق **ببطء مضاعف** |

**تناقض مقصود:** السلسلة سريعة، لكن **جملة الختام بطيئة جدًا**. التباطؤ المفاجئ يجعلها تعلق في الذاكرة.

## 8. الحياد والدقة

| القاعدة | التفصيل |
|---|---|
| المصادر | **منتقاة ومغلقة** — لا مصادر مفتوحة التحرير |
| الحدود | ما لا يُعرف يُقال صريحًا: «لا نعرف بعد» |
| التبسيط | يحذف تفاصيل، **لا يقلب حقائق** |
| الجدل | لا مواضيع علمية متنازع عليها في هذه السلسلة |
| الحلقات الصحية | لا نصيحة طبية — وصف لا توجيه |

> ⚠️ **حلقة «لماذا ننام؟»**: تصف وظيفة النوم، **ولا تعطي نصيحة طبية** ولا تحدّد ساعات نوم كتوصية. أي جملة توجيهية صحية تحتاج **مراجعًا طبيًا**.

## 9. الصوت

| الحقل | القيمة |
|---|---|
| ليلى | معلّقة عربية، نبرة **واضحة سريعة واثقة** |
| السرعة | ~140 كلمة/دقيقة |
| جملة الختام | ~80 كلمة/دقيقة — **نصف السرعة** |
| الموسيقى | إيقاع خفيف نشط، −18 dB |
| المؤثرات | ≤ 300ms · نغمة انتقال بين المقاطع |

## 10. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| جملة الختام | **تُصاغ لكل لغة** بما يجعلها قابلة للحفظ — لا تُترجم حرفيًا |
| المخططات | `language_neutral` — التسميات من الترجمة |
| الوحدات | متري + بديل حسب السوق |

⚠️ **جملة الختام هي أصعب عنصر ترجمة.** جملة قابلة للحفظ في العربية قد تكون ثقيلة في الإنجليزية. تُؤلَّف لكل لغة بمعنى واحد وصياغة مختلفة.

## 12. معايير قبول الحلقة

- [ ] المدة **2:00 ±5 ثوان** — دقيق.
- [ ] كل جملة ≤ 20 كلمة · **18–22 جملة**.
- [ ] **مفهوم واحد فقط**.
- [ ] الشعار ≤ 3 ثوان، والسؤال يبدأ مباشرة.
- [ ] **5–7 لقطات فقط**.
- [ ] **جملة ختام** واحدة قابلة للحفظ، تُنطق ببطء مضاعف وتُعرض بصريًا.
- [ ] النص على الشاشة **جملة الختام فقط**، من ملفات الترجمة.
- [ ] المصادر منتقاة ومغلقة.
- [ ] التبسيط لا يقلب حقيقة.
- [ ] حدود المعرفة تُذكر صريحًا عند اللزوم.
- [ ] 🔴 لا نصيحة طبية في الحلقات الصحية.
- [ ] 🔴 **مراجعة مراجع علمي** موثقة.
- [ ] 🔴 حلقة النوم: **مراجعة طبية** موثقة.
- [ ] لا وميض > 3Hz · لا صوت مفاجئ.
