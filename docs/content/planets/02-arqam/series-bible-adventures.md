# دليل السلسلة — مغامرات الأرقام

`Series Bible` · `continuous` · 6–8 · الإصدار 1.0

---

## 1. الفكرة في جملة

**نوما** فتاة تحلّ مشكلات كوكب أرقام بالعدّ والمنطق، ومعها **عدّاد** روبوت صغير يحسب بصوت مسموع، لكنه **يخطئ أحيانًا** فتصحّح له نوما — والطفل معها.

## 2. الفكرة المحورية: الروبوت يخطئ

هذا أهم قرار في السلسلة.

| لماذا | الأثر |
|---|---|
| الطفل يصحّح | يتحوّل من متلقٍّ إلى **مُقيِّم** — أعلى مستوى تفكير |
| الخطأ مقبول | يرى شخصية محبوبة تخطئ وتستمر، فيقلّ خوفه من الخطأ |
| التحقق مهارة | يتعلّم أن **يعيد العدّ للتأكد** لا أن يثق بالجواب الأول |
| بلا إحباط | الخطأ يقع على عدّاد لا على الطفل |

**قاعدة صارمة:** عدّاد يخطئ **مرة واحدة كل حلقة على الأكثر**، وخطؤه **منطقي مفهوم** (نسي عنصرًا · عدّ عنصرًا مرتين) لا عشوائيًا.

## 3. الشخصيات

### نوما

| الحقل | القيمة |
|---|---|
| العمر الظاهري | 8 سنوات |
| الشكل | عربية، شعر مجعّد قصير، نظارة مستديرة، حقيبة صغيرة |
| الملبس | قميص `Comet Cyan #00D6F5` + بنطال `Cosmic Indigo #1B236B` |
| الشخصية | منطقية، هادئة، **تتحقق قبل أن تجيب** |
| طريقة الكلام | جمل واضحة، تشرح خطوتها بصوت مسموع |
| ما لا تفعلها | لا تسخر من عدّاد · لا تتعالى · لا تعطي الجواب فورًا |

**عبارتها المميزة:** «هيا نتأكد.»

### عدّاد

| الحقل | القيمة |
|---|---|
| النوع | روبوت صغير كرويّ يطفو |
| الشكل | جسم كرويّ `Star Yellow #FFD34D` + شاشة صغيرة تعرض أرقامًا |
| الحجم | بحجم كرة قدم، يطفو بمستوى كتف نوما |
| الصوت | صوت آليّ **ودّي لا مخيف**، إيقاع منتظم |
| الشخصية | متحمس، سريع، **يستعجل فيخطئ** |
| الشاشة | تعرض الرقم الذي يحسبه — وهي **بيانات لعب لا نص واجهة** |

**عبارته المميزة:** «حسبتها! العدد هو...»

**قاعدة تصميم:** خطأ عدّاد يظهر على شاشته بلون `#FF9F1C` لا أحمر. الأحمر يوحي بالفشل، والبرتقالي يوحي بـ«أعد المحاولة».

## 4. العالم

كوكب أرقام: مدينة هندسية بسيطة — جسور، أبراج، حدائق مرتّبة. كل شيء **قابل للعدّ**: نوافذ، أعمدة، أشجار في صفوف.

| العنصر | القاعدة |
|---|---|
| الخلفية | مشهد واضح لكن **≤ 5 عناصر بارزة** |
| العناصر القابلة للعدّ | مرتّبة في صفوف أو مجموعات واضحة |
| الوقت | نهار |
| المزاج | مشرق، منظّم، ودّي |

## 5. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `limited_2d` |
| الخطوط | نظيفة، أدقّ قليلًا من سلسلة البراعم |
| عدد العناصر في اللقطة | ≤ 6 |
| حركة الكاميرا | بطيئة · لا اهتزاز |
| الانتقالات | تلاشٍ 400ms |
| الوميض | ممنوع > 3Hz |

## 6. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 12 كلمة** |
| السرعة | ~120 كلمة/دقيقة |
| الوقفة بين الجمل | 600ms |
| بعد سؤال | **صمت 4 ثوان** |
| النبرة | ودّية متحمسة قليلًا — **لا طفولية مصطنعة** |

### بنك عبارات نوما

**نجاح:** إجابة صحيحة، أحسنت! · تفكير ممتاز! · صحيح تمامًا! · لاحظت الفرق، جيد جدًا!

**محاولة:** ليست هذه، جرّب مرة أخرى · هيا نتأكد معًا · اقتربت! أعد العدّ · حاول مرة أخرى، أنت تفهمها

**تصحيح عدّاد:** انتظر يا عدّاد · هيا نتأكد · أعتقد أنك نسيت واحدًا · لنعدّ معًا مرة أخرى

**لا يوجد في بنكها:** أي عبارة تسخر من عدّاد أو تقلّل منه.

## 7. بنية الحلقة الثابتة

| المقطع | المدة | المحتوى |
|---|---:|---|
| افتتاحية | 0:00–0:15 | شعار + نوما وعدّاد |
| المشكلة | 0:15–0:50 | تظهر مشكلة تحتاج عدًّا |
| المحاولة الأولى | 0:50–1:40 | عدّاد يحسب — **وقد يخطئ** |
| التحقق | 1:40–2:30 | نوما والطفل يعيدان العدّ |
| الحل | 2:30–3:20 | تُحلّ المشكلة |
| التطبيق | 3:20–4:05 | سؤال للطفل |
| الخاتمة | 4:05–4:30 | تلخيص المفهوم + دعوة للعبة |

**المدة: 4:30 دقيقة.**

## 8. الصوت

| الحقل | القيمة |
|---|---|
| صوت نوما | معلّقة عربية، طفلة أو شابة بنبرة طفلة **مقنعة** |
| صوت عدّاد | **معالجة آلية خفيفة** على صوت بشري — لا تركيب صناعي كامل |
| الأرقام | مقاطع منفصلة 1–20 |
| الموسيقى | إيقاع خفيف نشط، −18 dB |
| مؤثر عدّاد | نغمة حسابية قصيرة ≤ 200ms عند كل حساب |

### مقاطع الأرقام 1–20

`asset-vo-num-1` … `asset-vo-num-20` — **منفصلة إلزاميًا**.

## 9. المسموح والممنوع

| ✅ مسموح | ❌ ممنوع |
|---|---|
| خطأ عدّاد المنطقي | خطأ عشوائي غير مفهوم |
| العدّ حتى 20 | أعداد > 20 في هذه السلسلة |
| جمع وطرح **بصريان** | رموز `+` و`−` و`=` كمفاهيم مجرّدة أولًا |
| إعادة العدّ للتحقق | مؤقتات · تنافس |
| | السخرية من الخطأ |
| | أصوات مفاجئة · وميض > 3Hz |
| | نص مطبوع داخل الصور |

**قاعدة رياضية:** الجمع والطرح يُقدَّمان **بصريًا أولًا** (مجموعتان تندمجان / مجموعة تنقص) قبل أي رمز. الرمز يظهر في الحلقة 4 وما بعدها فقط، وبعد فهم المعنى.

## 10. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | **`translatable` بالكامل** |
| الأرقام | `numeral_system: auto` |
| شاشة عدّاد | تعرض **رقمًا** — يتبع `numeral_system` |
| اتجاه العدّ والمجموعات | يتبع اتجاه القراءة |
| صوت عدّاد | يُسجَّل لكل لغة بنفس المعالجة الآلية |

## 12. معايير قبول الحلقة

- [ ] المدة 4:30 ±15 ثانية.
- [ ] كل جملة ≤ 12 كلمة.
- [ ] هدف تعليمي **واحد**.
- [ ] ≤ 6 عناصر في اللقطة.
- [ ] خطأ عدّاد **مرة واحدة كحد أقصى** ومنطقي.
- [ ] نوما **لا تسخر** من عدّاد في أي موضع.
- [ ] مرحلة التحقق موجودة وواضحة.
- [ ] الجمع/الطرح **بصري قبل الرمز**.
- [ ] وقفة 4 ثوان بعد كل سؤال.
- [ ] مقاطع الأرقام منفصلة.
- [ ] شاشة عدّاد تتبع `numeral_system`.
- [ ] لا مؤقت · لا وميض > 3Hz · لا صوت مفاجئ.
- [ ] لا نص مطبوع في أي إطار.
- [ ] مراجعة تربوية موثقة.
