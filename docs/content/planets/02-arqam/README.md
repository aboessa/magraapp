## قاعدة الأرقام في الكوكب كله

`numeral_system: "auto"` — تُعرض `٣` أو `3` حسب المنطقة، و**تُخزَّن القيمة العددية فقط**. لا تُخزَّن قيمة معروضة كبيانات دائمة.
