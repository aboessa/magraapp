# دليل السلسلة — عدّ معي

`Series Bible` · `presenter` · 3–5 · الإصدار 1.0

---

## 1. الفكرة في جملة

برنامج قصير تقدّمه **سُهى**، تعدّ فيه مع الطفل أشياء بسيطة من عالمه، خطوة واحدة في كل حلقة.

## 2. لماذا `presenter` لا `continuous`

| السبب | التفصيل |
|---|---|
| بلا حمل قصصي | طفل الثالثة يصعب عليه متابعة قصة **وتعلّم مفهوم** معًا |
| أرخص إنتاجًا | `motion_story` — صور ثابتة وحركة كاميرا |
| قابل للتوسع | إضافة حلقة لا تحتاج استمرارية قصصية |
| تركيز أعلى | المقدمة تخاطب الطفل مباشرة، لا تحكي عن غيره |

## 3. المقدمة — سُهى

| الحقل | القيمة |
|---|---|
| النوع | **شخصية مرسومة** لا ممثلة حقيقية |
| العمر الظاهري | شابة عشرينية |
| الشكل | عربية، شعر قصير مربوط، ملابس بسيطة بلون `Comet Cyan #00D6F5` |
| الموضع | يمين الكادر دائمًا *(يسار في LTR)*، تشغل ثلث الكادر |
| النبرة | هادئة، واضحة، **غير مبالغة في البهجة** |
| ما تفعله | تشير · تعدّ بإصبعها · تنتظر |
| ما لا تفعله | لا تصفّق كثيرًا · لا تصرخ · لا تستعجل · لا تقول «خطأ» |

### لماذا مرسومة لا حقيقية

| السبب | التفصيل |
|---|---|
| الاتساق | لا تتغير ملامحها أو ملابسها بين الحلقات |
| التكلفة | لا تصوير ولا موقع ولا إعادة تصوير |
| الترجمة | يمكن تبديل الصوت لأي لغة بلا إعادة تصوير |
| الحقوق | لا عقود ظهور ولا حقوق صورة شخصية طويلة الأمد |

## 4. اليد العادّة

عنصر بصري ثابت: **يد سُهى** تظهر قريبة وتعدّ بإصبعها، ويظهر رقم بجانب كل عنصر عند عدّه.

| القاعدة | القيمة |
|---|---|
| سرعة العدّ | **عنصر واحد كل 1.2 ثانية** — بطيء مقصود |
| الرقم | يظهر بجانب العنصر، `Star Yellow #FFD34D` |
| الترتيب | من اليمين لليسار في `ar`، ومن اليسار في `en` |
| بعد العدّ | كل الأرقام تبقى ظاهرة لثانية، ثم يبقى **الأخير** فقط |

**التقنية التعليمية:** بقاء الرقم الأخير وحده يعلّم **مبدأ العدد الأصلي** — أن آخر رقم قلته هو عدد المجموعة كلها. هذا مفهوم لا يفهمه كل طفل تلقائيًا.

## 5. العالم البصري

| العنصر | القاعدة |
|---|---|
| الخلفية | لون واحد مسطّح `#0B1026` أو `#1B236B` — بلا مشهد |
| العناصر | على خط أفقي واحد، متساوية المسافات |
| عدد العناصر | **≤ 5 دائمًا** في هذه السلسلة |
| الحجم | كل العناصر **بنفس الحجم** — الحجم لا يدلّ على العدد |
| الحركة | العنصر يهتز بلطف عند عدّه فقط |

**قاعدة حاسمة:** العناصر **متطابقة الحجم والشكل** في المستويات الأولى. اختلاف الحجم يشوّش تقدير العدد عند الطفل الصغير.

## 6. الألوان

| الاستخدام | اللون |
|---|---|
| الخلفية | `#0B1026` |
| سُهى | `#00D6F5` |
| الأرقام | `#FFD34D` |
| العناصر المعدودة | `#FF6FAE` أو `#FF9F1C` |
| النص | `#F2F6FF` |

## 7. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 6 كلمات** |
| السرعة | ~95 كلمة/دقيقة |
| الوقفة بين الجمل | 800ms |
| بعد سؤال | **صمت 3 ثوان** |
| عدّ الأرقام | 1.2 ثانية لكل رقم |
| التكرار | كل عدّ يُكرَّر **مرتين** |

### بنك عبارات سُهى

**نجاح:** أحسنت! · نعم، صحيح! · عددت جيدًا! · ممتاز! · هكذا تمامًا!

**محاولة:** هيا نعدّ مرة أخرى · لا بأس، معًا · انظر معي · جرّب مرة أخرى

**دعوة:** عُدّ معي · هل ترى؟ · دورك الآن

## 8. بنية الحلقة الثابتة

| المقطع | المدة | المحتوى |
|---|---:|---|
| افتتاحية | 0:00–0:12 | شعار + سُهى ترحّب |
| التقديم | 0:12–0:35 | سؤال الحلقة |
| المثال 1 | 0:35–1:10 | عدّ مع سُهى |
| المثال 2 | 1:10–1:45 | عدّ مع سُهى |
| المثال 3 | 1:45–2:15 | عدّ مع سُهى |
| التطبيق | 2:15–2:45 | الطفل يعدّ وحده |
| الخاتمة | 2:45–3:00 | تلخيص + دعوة للعبة |

**المدة: 3:00 دقيقة.**

## 9. الصوت

| الحقل | القيمة |
|---|---|
| صوت سُهى | معلّقة عربية، نبرة **هادئة واضحة غير طفولية مصطنعة** |
| السرعة | ~95 كلمة/دقيقة |
| الأرقام | **مقاطع منفصلة** لكل رقم 1–5 |
| الموسيقى | خفيفة جدًا، −18 dB، قابلة للإيقاف |
| المؤثرات | نقرة عدّ ≤ 80ms · لا أصوات مفاجئة |

### مقاطع الأرقام — إلزامية منفصلة

| المعرف | النص |
|---|---|
| `asset-vo-num-1` | «واحد» |
| `asset-vo-num-2` | «اثنان» |
| `asset-vo-num-3` | «ثلاثة» |
| `asset-vo-num-4` | «أربعة» |
| `asset-vo-num-5` | «خمسة» |

**لا يجوز تسجيل «واحد اثنان ثلاثة» كمقطع واحد.** المحرك ينطقها بالتتابع متزامنة مع إبراز كل عنصر، وبسرعات مختلفة حسب السياق.

## 10. المسموح والممنوع

| ✅ مسموح | ❌ ممنوع |
|---|---|
| عناصر مألوفة: نجوم، تفاح، كرات | مؤقتات · ضغط زمني |
| العدّ ببطء والتكرار | أعداد > 5 في هذه السلسلة |
| الصمت للتفكير | أشكال هندسية مجرّدة معقّدة |
| اليد العادّة | اختلاف أحجام العناصر في المستويات الأولى |
| | أصوات مفاجئة · وميض > 3Hz |
| | نص مطبوع داخل الصور |

## 11. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | **`translatable` بالكامل** — لا شيء لغويًا خاصًا |
| الأرقام | `numeral_system: auto` — العرض حسب المنطقة، التخزين عددي |
| اتجاه العدّ | يتبع اتجاه القراءة: يمين←يسار في `ar`، يسار←يمين في `en` |
| سُهى | موضعها ينعكس مع الاتجاه |

## 13. معايير قبول الحلقة

- [ ] المدة 3:00 ±10 ثوان.
- [ ] كل جملة ≤ 6 كلمات.
- [ ] هدف تعليمي **واحد**.
- [ ] ≤ 5 عناصر، **متطابقة الحجم**.
- [ ] العدّ 1.2 ثانية لكل عنصر، ويُكرَّر مرتين.
- [ ] الرقم الأخير يبقى وحده بعد العدّ.
- [ ] مقاطع الأرقام **منفصلة**.
- [ ] وقفة 3 ثوان بعد كل سؤال.
- [ ] تُفهم بالصوت وحده، وبالبصر وحده.
- [ ] لا مؤقت · لا وميض > 3Hz · لا صوت مفاجئ.
- [ ] لا نص مطبوع في أي إطار.
- [ ] اتجاه العدّ يتبع اللغة.
- [ ] مراجعة تربوية موثقة.
