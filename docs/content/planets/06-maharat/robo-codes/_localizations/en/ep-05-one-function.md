## The Mission

An 8×8 grid with four obstacles. The path has **three identical corners**: at each corner Robo advances two tiles then turns right.

## The Concept

**The function:** a name you give to a **group of commands** to use it in more than one place.

## Learning Objective

**One goal:** the child understands that a function is useful when **a pattern repeats in different places**, and that the name is its benefit.

Criterion: finds the repeating pattern in a given program, defines a function that covers it, and names it descriptively — in 3 of 4 tries.

## 🔴 The difference between repetition and a function — the first thing the episode settles

| Item | `repeat` | `function` |
|---|---|---|
| what it handles | 🔴 **one command** that repeats | 🔴 **a group of commands** that repeats |
| the place | consecutive in one spot | **scattered places** |
| the example | move × 6 | move · move · turn right — **three times in three corners** |
| the first benefit | a shorter program | 🔴 **a name that clarifies the meaning** |

> 🔴 **A child who learned `repeat` in episode 3 will try to use it here, and it will not be enough.**
>
> The reason is that the pattern is **three different commands** not one command, and it repeats in **scattered places** not consecutive ones. This failure is deliberate and designed: the best gateway to the function is **the limit of repetition**.

## 🔴 The Signature Decision: the name is the benefit, not the shortness

| ❌ rejected framing | ✅ the adopted framing |
|---|---|
| "the function shortens your program" | 🔴 "the function names what it does" |
| a name like `a` or `f1` | 🔴 a descriptive name: **"turn the corner"** |
| the benefit is fewer blocks | 🔴 the benefit is **a program that reads** |
| measuring success by length | measuring it by clarity |

> 🔴 **If the benefit were shortness alone, `repeat` would be more efficient.**
>
> The function's real benefit is that it **gives meaning to a group of steps**. And a program that says "turn the corner · turn the corner · turn the corner" **reads and is understood**, unlike nine scattered steps.
>
> This is the child's first encounter with **abstraction**: gathering details under a name, so you deal with the name and forget the details. And we do not call it "abstraction" in the episode — the concept is practiced, and the term comes at an older age.
>
> 🔗 **And naming is a language skill too**, with a root in [the Abjad planet](../../01-abjad/README.md): the precise word saves a sentence.

## 🔴 The failure: a wrong pattern, not a wrong name

| ❌ rejected failure | ✅ the failure used |
|---|---|
| forgot to define the function | 🔴 defined a function for **a group that does not repeat** |
| wrote the name wrong | the name is sound, **and the group is wrong** |
| called the function once | 🔴 **the function is technically correct and useless** |

🔴 **A function called once is a longer program, not a shorter one.** And this failure teaches the correct order of work: **look for the repetition first, then name it**.

> | Option | Verdict |
> |---|---|
> | `turn the corner` | ✅ it says **what it does** |
> | `f1` | ❌ says nothing |
> | `Robo moves` | ❌ too general · fits any function |
>
> **`robo-moves` is a half-right distractor**: a readable name, with no distinctive meaning. And this is the subtlest lesson in naming.

## Parent Guide

> **What is your child learning?**
> To give a **name to a group of steps**. This is called a **function**, written in programming as `function`.
>
> **🔴 And the benefit is not shortness, but the name**
> If the benefit were shortening the program, `repeat` from episode three would suffice. The function's real benefit is that it **gives meaning** to a group of steps, so the program becomes **readable**.
>
> A program that says "turn the corner · turn the corner · turn the corner" is understood at a glance. And nine scattered steps are not.
>
> This is your child's first encounter with **abstraction**: gathering details under a name, so they deal with the name and forget the details. And we do not name the concept in the episode — it is practiced now, and named at an older age.
>
> **🔴 And the program in the episode succeeded**
> This is the first episode where the program works and the work remains incomplete. Robo **arrived**, but one corner had a name and two had none.
>
> On purpose. We move your child from the question "**does it work?**" to the question "**does it read?**" — a real transition in a programmer's maturity.
>
> **🔴 The correct order: search then name**
> A child who learns the function tends to define it for everything. And the episode tells them: "**Do not start by writing a function. Start by searching.**"
>
> The function is a tool **for an existing pattern**, not a template to impose. And a function called once **makes the program longer, not shorter**.
>
> **What this means for you in practice**
> If they show you their program, ask two questions: "**Which group repeated?**" then "**What does the name of this function say?**"
>
> The second question is more useful than it seems. If the name is `f1` or `stuff`, the name did not do its job. **And good naming is a language skill before it is a programming one** — with a root in [the Abjad planet](../../01-abjad/README.md).
>
> **The episode is 6:30 like episode four** — the function needs the incomplete success shown, and that takes time.

## Family Activity — optional

> **Name the routine — 10 minutes · no screen**
>
> 1. Ask your child to list the steps of something they do every day *(setting up their bag · making their bed)*.
> 2. **Write all the steps**, even if there are seven or eight.
> 3. Ask them: "**Which group of these steps repeats in other tasks?**"
> 4. Give each group **a two-word name** that says what it does.
> 5. 🔴 Test the name: "If I said this name alone to you, **would I know what to do?**"
> 6. If the answer is no, **change the name**, not the steps.
>
> 🔴 **The fifth step is the activity.** Testing the name is more useful than choosing the name.
>
> 🔴 **And do not accept a general name** like "stuff" or "prep." The name must exclude everything else.
>
> **And when they find that one group repeats in two different tasks, they have understood the function.** That moment is the goal.
