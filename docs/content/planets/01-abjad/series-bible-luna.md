> هذا المستند ومرجع الهوية أدناه يلغيـان أي وصف سابق للونا بشعر ظاهر أو فستان وردي، وأي توجيه إنتاجي `limited_2d`. المرجع الرسمي هو Luna v2 فقط.

- تُعيد كل حلقة استخدام **نفس** `identity_id + visual_version + reference_pack_sha256`؛ لا يُولَّد Character Sheet جديد لكل حلقة.
- الـsheet المعتمد يقفل الوجه، النسب، الحجاب، الملابس، الألوان، ودبوس الهلال. هو مرجع **هوية** حتى عند إخراج الشخصية بأسلوب 3D، وليس أمرًا بتحويل الإخراج إلى 2D.
- أقفال نجمي والعالم والـprops والأسلوب والصوت في هذا الدليل جزء من الـCanon. يمكن إضافة `world_sheet` أو `prop_sheet` أو `style_frame` إلى إصدار لاحق من الحزمة.
- أي شخصية متكررة جديدة أو تغيير في الشكل/الملابس/العالم/الـprops يفرض إصدارًا جديدًا (`luna-v3` مثلًا)، بصمة جديدة، ومراجعة جديدة؛ لا يجوز استبدال ملفات v2 في مكانها.
- كل manifest بصري يجب أن يحمل حزمة معتمدة مطابقة لـ`series_slug`. الحزمة الناقصة أو غير المعتمدة أو ذات بصمة قديمة تمنع اعتماد الإنفاق والـdispatch.

## 1. الفكرة في جملة

**لونا** طفلة فضولية تعيش على كوكب أبجد، ومعها صديقها **نجمي**، وفي كل حلقة تكتشف كلمة جديدة من عالمها.

## 2. الشخصيات

### لونا

| الحقل | القيمة |
|---|---|
| العمر الظاهري | 5 سنوات |
| الشكل | طفلة عربية ببشرة قمحية دافئة، خدّين مستديرين، عينين بنيتين واسعتين، وحجاب أصفر ذهبي يغطي الشعر والرقبة بالكامل |
| الملبس | تونيك أصفر ذهبي طويل الأكمام بطول الركبة + بنطال وحذاء `Dark Teal` + دبوس هلال فضي عند الكتف الأيسر |
| ثوابت الهوية | الوجه والنسب والخامات والمقياس والزي ثابتة؛ لا شعر ظاهر · لا تغيير ملابس · لا اختلاف عمر |
| الطول في الكادر | تشغل ثلث الكادر تقريبًا؛ دائمًا في مستوى نظر الطفل |
| الشخصية | فضولية، مبتهجة، **لا تعرف كل شيء** — تتعلم مع الطفل |
| طريقة الكلام | جمل قصيرة جدًا، نبرة دافئة، تسأل أكثر مما تخبر |
| ما لا تفعله | لا تصرخ · لا تسخر · لا تصحّح بقسوة · لا تقول «خطأ» |

**قاعدة تربوية:** لونا **ليست معلّمة**. هي رفيقة تكتشف مع الطفل. لو عرفت كل شيء، صار الطفل متلقيًا لا مشاركًا.

### نجمي

| الحقل | القيمة |
|---|---|
| النوع | نجمة صغيرة حيّة، بلا أطراف |
| الشكل | نجمة خماسية ذهبية مستديرة الأطراف، بعينين بنيتين داكنتين وفم صغير؛ بلا ملابس أو إضافات |
| الحجم | بحجم كف لونا |
| الحركة | يطفو ويتأرجح بلطف؛ **لا يتحرك بسرعة** |
| الصوت | نغمة بلورية قصيرة بلا كلام، مع توهج `Comet Cyan` خافت عند توجيه الانتباه |
| الوظيفة | يوجّه نظر الطفل: يتوهج فوق العنصر المهم |

**قاعدة تصميم:** نجمي **لا يتكلم بكلمات**. هذا يجعله مفهومًا في كل اللغات بلا ترجمة، ويقلّل الحمل السمعي على الطفل.

## 3. العالم

كوكب أبجد حديقة تعليمية ثلاثية الأبعاد آمنة: تلال نيلية ناعمة، ممرات كريمية دافئة، نباتات مستديرة مرجانية وسماوية، نجوم ذهبية صغيرة، وسماء كونية كحلية عميقة.

| العنصر | القاعدة |
|---|---|
| الخلفية | ≤ 3 عناصر مرئية · عمق جوي ناعم · بلا تفاصيل مزدحمة |
| الحروف في المشهد | لا حروف أو كلمات مقروءة؛ الزخارف إن وجدت تجريدية فقط |
| الوقت | نهار دافئ دائمًا — لا ليل مخيف |
| السماء | داكنة لكن مضاءة بأمان، **بلا ظلام مطبق ولا غيوم عاصفة** |
| الـprops المتكررة | تفاحة حمراء بورقة خضراء · كرة teal بشريط أصفر عريض · قط زنجبيل بلا ملابس · بيت كريمي بسقف مرجاني وباب cyan |

## 4. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `stylized_3d_cinematic` — تحريك preschool معاصر بجودة استوديو |
| الخامات والإضاءة | خامات PBR ناعمة، طيات قماش نظيفة، تظليل بشرة خفيف، إضاءة عالمية وضوء حواف حجمي دافئ |
| التصميم | أحجام مستديرة محببة، تعبيرات وجه واضحة، حركة جسم طبيعية، عمق مجال لطيف، بلا مظهر clip-art مسطح |
| الألوان | من [هوية مجرة](../../../../brandcolor.md) مع أقفال Luna v2 أدناه |
| عدد العناصر في اللقطة | **≤ 4** |
| حركة الكاميرا | مستوى نظر الطفل؛ dolly أو arc بطيء فقط · أفق ثابت · لا اهتزاز أو زووم سريع |
| الانتقالات | انتقالات ناعمة بلا قطع حاد أو حركة مفاجئة |
| الوميض | **ممنوع** أي وميض > 3Hz |

## 5. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 6 كلمات** |
| المفردات | فصحى مبسطة · كلمات يعرفها طفل 4 سنوات |

| التكرار | مقبول ومطلوب — الطفل يتعلم بالتكرار |
| ممنوع | «خطأ» · «لا» الحادة · السخرية · المقارنة بأطفال |

**عند المحاولة:** جرّب مرة أخرى · قريب جدًا! · هيا ننظر معًا · لا بأس، حاول

**للفت الانتباه:** انظر معي · هل ترى؟ · تعال نكتشف

المصدر الموحّد: [سياسة التشجيع](../../../games/04-encouragement-and-failure.md).

## 6. النطق والصوت

| الحقل | القيمة |
|---|---|
| صوت لونا | صوت أنثوي عربي شاب واحد، دافئ وفضولي وطبيعي؛ لا مذيعة · لا روبوت · لا صراخ |
| مسار الإنتاج الكرتوني | الحوار والموسيقى والمؤثرات تُولَّد داخل نموذج الفيديو وتُحفظ في الـmaster؛ الدبلجة الخارجية مسار إصلاح استثنائي فقط |
| الاتساق | نفس هوية الصوت في كل المقاطع والحلقات، مع مزامنة شفاه عربية دقيقة عند ظهور لونا |
| السرعة | ~100 كلمة/دقيقة (بطيئة) |
| مستوى الصوت | الحوار في المقدمة وقابل للفهم؛ الهدف النهائي ‎−16 LUFS |
| الموسيقى | خفيفة وتحت الكلام بوضوح، **قابلة للإيقاف** في المنتج |
| المؤثرات | ≤ 400ms · لا أصوات مفاجئة إطلاقًا · نجمي يصدر نغمة بلورية قصيرة فقط |

**نطق الحروف:** يُنطق الحرف **بصوته** لا باسمه: «بَ» قبل «باء»، «مَ» قبل «ميم». اسم الحرف يُقدَّم لاحقًا للأكبر.

## 9. قاعدة النص داخل الصور

> **لا نص مكتوب داخل أي صورة.** النص من ملفات الترجمة `.arb` دائمًا.

الاستثناء الوحيد: **بيانات الحروف والأرقام** في حلقات التتبّع، وهي بيانات لعب لا نص واجهة، ومحزَّمة لكل لغة أصلًا.
