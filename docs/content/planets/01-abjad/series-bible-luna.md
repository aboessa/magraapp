# دليل السلسلة — لونا تكتشف الكلمات

`Series Bible` · إلزامي قبل بدء الإنتاج · الإصدار 1.0

---

## 1. الفكرة في جملة

**لونا** طفلة فضولية تعيش على كوكب أبجد، ومعها صديقها **نجمي**، وفي كل حلقة تكتشف كلمة جديدة من عالمها.

## 2. الشخصيات

### لونا

| الحقل | القيمة |
|---|---|
| العمر الظاهري | 5 سنوات |
| الشكل | طفلة عربية، شعر أسود مجدول بضفيرتين، عيون واسعة بنية |
| الملبس | فستان بسيط بلون `Coral Pink #FF6FAE` + حزام نجوم `Star Yellow #FFD34D` |
| الطول في الكادر | تشغل ثلث الكادر تقريبًا؛ دائمًا في مستوى نظر الطفل |
| الشخصية | فضولية، مبتهجة، **لا تعرف كل شيء** — تتعلم مع الطفل |
| طريقة الكلام | جمل قصيرة جدًا، نبرة دافئة، تسأل أكثر مما تخبر |
| ما لا تفعله | لا تصرخ · لا تسخر · لا تصحّح بقسوة · لا تقول «خطأ» |

**قاعدة تربوية:** لونا **ليست معلّمة**. هي رفيقة تكتشف مع الطفل. لو عرفت كل شيء، صار الطفل متلقيًا لا مشاركًا.

### نجمي

| الحقل | القيمة |
|---|---|
| النوع | نجمة صغيرة حيّة، بلا أطراف |
| الشكل | نجمة خماسية `Star Yellow #FFD34D` بوجه بسيط: عينان وفم |
| الحجم | بحجم كف لونا |
| الحركة | يطفو ويتأرجح بلطف؛ **لا يتحرك بسرعة** |
| الصوت | نغمات قصيرة لا كلام — `Comet Cyan` توهج عند الفرح |
| الوظيفة | يوجّه نظر الطفل: يتوهج فوق العنصر المهم |

**قاعدة تصميم:** نجمي **لا يتكلم بكلمات**. هذا يجعله مفهومًا في كل اللغات بلا ترجمة، ويقلّل الحمل السمعي على الطفل.

## 3. العالم

كوكب أبجد: تلال ناعمة، حروف عربية كبيرة مبعثرة كصخور ودّية، سماء `Midnight Navy #0B1026` بنجوم هادئة.

| العنصر | القاعدة |
|---|---|
| الخلفية | ≤ 3 عناصر مرئية · بلا تفاصيل مزدحمة |
| الحروف في المشهد | زخرفية فقط، **غير مقروءة كنص وظيفي** |
| الوقت | نهار دافئ دائمًا — لا ليل مخيف |
| السماء | داكنة لكن **بلا ظلام مطبق ولا غيوم عاصفة** |

## 4. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `limited_2d` |
| الخطوط | سميكة ناعمة، بلا زوايا حادة |
| الألوان | من [هوية مجرة](../../../../brandcolor.md) فقط |
| عدد العناصر في اللقطة | **≤ 4** |
| حركة الكاميرا | بطيئة جدًا؛ لا اهتزاز · لا زووم سريع |
| الانتقالات | تلاشٍ ناعم 400ms · لا انتقالات حادة |
| الوميض | **ممنوع** أي وميض > 3Hz |

## 5. قواعد الحوار

| القاعدة | القيمة |
|---|---|
| طول الجملة | **≤ 6 كلمات** |
| المفردات | فصحى مبسطة · كلمات يعرفها طفل 4 سنوات |
| السرعة | بطيئة، مع وقفة 800ms بين الجمل |
| الأسئلة | سؤال واحد في المرة، ثم **صمت 3 ثوان** للطفل |
| التكرار | مقبول ومطلوب — الطفل يتعلم بالتكرار |
| ممنوع | «خطأ» · «لا» الحادة · السخرية · المقارنة بأطفال |

### بنك عبارات لونا

**عند النجاح:** أحسنت! · نعم، صحيح! · وجدتها! · جميل جدًا! · هكذا تمامًا!

**عند المحاولة:** جرّب مرة أخرى · قريب جدًا! · هيا ننظر معًا · لا بأس، حاول

**للفت الانتباه:** انظر معي · هل ترى؟ · تعال نكتشف

المصدر الموحّد: [سياسة التشجيع](../../../games/04-encouragement-and-failure.md).

## 6. النطق والصوت

| الحقل | القيمة |
|---|---|
| صوت لونا | معلّقة عربية، نبرة طفولية دافئة **غير مصطنعة** |
| السرعة | ~100 كلمة/دقيقة (بطيئة) |
| مستوى الصوت | ‎−16 LUFS |
| الموسيقى | خفيفة، −18 dB تحت الكلام، **قابلة للإيقاف** |
| المؤثرات | ≤ 400ms · لا أصوات مفاجئة إطلاقًا |

**نطق الحروف:** يُنطق الحرف **بصوته** لا باسمه: «بَ» قبل «باء»، «مَ» قبل «ميم». اسم الحرف يُقدَّم لاحقًا للأكبر.

## 9. قاعدة النص داخل الصور

> **لا نص مكتوب داخل أي صورة.** النص من ملفات الترجمة `.arb` دائمًا.

الاستثناء الوحيد: **بيانات الحروف والأرقام** في حلقات التتبّع، وهي بيانات لعب لا نص واجهة، ومحزَّمة لكل لغة أصلًا.

## 10. الترجمة

| البند | القاعدة |
|---|---|
| لغة الإطلاق | `ar` — فصحى مبسطة |
| الموجة 2 | `en`, `fr` |
| نجمي | **لا يحتاج ترجمة** — لا يتكلم بكلمات |
| حلقات المفردات (1، 2، 5، 6) | قابلة للترجمة |
| حلقات الحروف (3، 4) | **`language_specific` — تُؤلَّف لكل لغة ولا تُترجم** |

السبب في [التعدد اللغوي](../../../games/01-localization-i18n.md): الأبجدية واتجاه الكتابة وأشكال الحرف تختلف كليًا.

## 12. معايير قبول الحلقة

- [ ] المدة 3:00 ±10 ثوان.
- [ ] كل جملة ≤ 6 كلمات.
- [ ] هدف تعليمي **واحد** مربوط بـ`learning_objective_id`.
- [ ] ≤ 4 عناصر في كل لقطة.
- [ ] الترجمة المغلقة `captions_ar_url` موجودة.
- [ ] تُفهم الحلقة **بالصوت وحده**، وبالبصر وحده.
- [ ] لا نص مطبوع في أي إطار.
- [ ] لا وميض > 3Hz · لا صوت مفاجئ.
- [ ] مراجعة تربوية ولغوية موثقة.
- [ ] حقوق الصوت والموسيقى موثقة.
- [ ] لعبة مرتبطة على نفس الهدف.
