# دليل السلسلة — حكاية هادئة

`Series Bible` · `anthology` · 3–5 · `pre_reader` · الإصدار 1.0

> **أصغر جمهور في المنصّة، وأشدّ قيود.** طفل الثالثة لا يقرأ، وينام بعد دقائق، ويتأثّر بأي صوت مفاجئ.

---

## 1. الفكرة في جملة

حكاية قصيرة جدًا بثمان صفحات، مسرودة كاملة، بلا حدث مقلق، تنتهي بسكون.

## 2. مواصفات الوحدة

| الحقل | القيمة |
|---|---|
| الصفحات | **8 بالضبط** |
| المدة | 2:30 – 2:50 |
| الجملة | 🔴 **≤ 8 كلمات** |
| الجمل لكل صفحة | **1–2** |
| السرد | 🔴 **كامل إلزامي** — لا يقرأ |
| النص على الشاشة | يُعرض **للكبير** لا للطفل |
| الوضع الافتراضي | **اقرأ لي** |
| المؤثّرات | ≤ 300ms · طبيعية هادئة |
| الموسيقى | −24 dB · تنتهي قبل الصفحة الثامنة |

🔴 **السرد الكامل ليس ميزة بل شرط وجود.** قصة بلا صوت في هذا العمر **غير قابلة للاستخدام**.

## 3. 🔴 قواعد العمر 3–5

| # | القاعدة | السبب |
|---:|---|---|
| 1 | 🔴 **لا شخصية تختفي** | قلق انفصال في هذا العمر |
| 2 | 🔴 **لا شخصية تبكي أكثر من صفحة** | يبكي الطفل معها |
| 3 | 🔴 **لا ظلام كامل في أي صفحة** | خوف الظلام في قمّته |
| 4 | 🔴 **لا صوت حيوان مرتفع** | تنبيه مفاجئ |
| 5 | 🔴 **لا فقدان ولا موت** بأي صورة | لا أدوات لمعالجته |
| 6 | 🔴 **لا سؤال في نهاية القصة** | لا يجيب · والنوم ليس اختبارًا |
| 7 | 🔴 **شخصية واحدة أو اثنتان فقط** | حمل معرفي |
| 8 | 🔴 **الأمّ أو الأب حاضران** في القصص التي فيها نوم | أمان |

> 🔴 **القاعدة 1 مطلقة:** لا شخصية تغيب عن الكادر بلا تفسير فوري، ولا «أين ذهب؟». الطفل في الثالثة يفسّر الغياب **فقدانًا**.
>
> **والقاعدة 3:** أغمق صفحة `brightness = 0.70` وفيها **مصدر ضوء مرئي** — قمر أو نافذة أو مصباح خفيف. الظلام الكامل غير موجود في السلسلة كلها.

## 4. البنية الثابتة — 8 صفحات

| الصفحة | الوظيفة | `brightness` | الحركة |
|---:|---|---:|---|
| 1 | **من؟** — الشخصية في مكانها | 1.00 | `kenburns_slow` |
| 2 | **ماذا يفعل؟** — نشاط عادي | 0.97 | `kenburns_slow` |
| 3 | **تغيّر صغير** | 0.94 | `pan_slow` |
| 4 | 🔴 **الذروة الصغيرة** | 0.90 | `pan_slow` |
| 5 | **يبدأ الحلّ** | 0.86 | `kenburns_slow` |
| 6 | **يعود / يجد** | 0.82 | `kenburns_slow` |
| 7 | **الاستقرار** | 0.76 | 🔴 `static` |
| 8 | 🔴 **سكون — بلا حدث** | 0.70 | 🔴 `static` |

🔴 **«الذروة الصغيرة» في الصفحة 4 بالضبط** — منتصف القصة. وهي **صغيرة**: مطر يبدأ · ريح تهبّ · شيء يسقط. **لا خطر، ولا خوف، ولا ضياع.**

## 5. الشخصيات

| الحقل | القيمة |
|---|---|
| العدد | 🔴 **1–2 فقط** |
| النوع | حيوان لطيف · أو طفل · أو شيء مشخَّص |
| الحجم البصري | **كبير في الكادر** — يميّزه الطفل بسرعة |
| التعبير | واضح جدًا · بسيط · 🔴 **بلا مبالغة مفزعة** |
| العيون | 🔴 **كبيرة ودّية** — لا حادّة ولا مظلمة |
| الأسنان | 🔴 **غير مرئية** عند أي حيوان |

🔴 **قاعدة الأسنان:** أي حيوان — ولو أرنبًا — بأسنان مرئية يبدو مخيفًا لطفل الثالثة. الأفواه مغلقة أو مبتسمة بلا أسنان.

## 6. الراوي

| الحقل | القيمة |
|---|---|
| النوع | صوت فقط |
| النبرة | 🔴 **هادئة بطيئة دافئة** — كأنها تُقال في غرفة مظلمة |
| السرعة | 🔴 **~90 كلمة/دقيقة** — الأبطأ في المنصّة |
| الحجم | ثابت · 🔴 **بلا تصعيد** |
| الشخصيات | يُغيّر نبرته قليلًا · 🔴 **بلا تمثيل صاخب** |

🔴 **~90 كلمة/دقيقة** مقابل 115–140 في الكواكب الأخرى. البطء **أداة تهدئة** لا خيارًا أسلوبيًا.

## 7. الأسلوب البصري

| الحقل | القيمة |
|---|---|
| مستوى الإنتاج | `motion_story` |
| الأسلوب | حدود ناعمة · أشكال مستديرة · 🔴 **لا زوايا حادّة** |
| الألوان | `#FECA57` أساسي + دافئة خافتة |
| التباين | متوسط · 🔴 **لا أسود خالص ولا أبيض ناصع** |
| التفاصيل | 🔴 **قليلة جدًا** — 2–4 عناصر لكل صفحة |
| النص | أسفل الصفحة · خطّ كبير · للكبير |

🔴 **2–4 عناصر لكل صفحة.** طفل الثالثة لا يمسح الصفحة بصريًا. العنصر الخامس يُفقد الأول.

## 8. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| النص | ≤ 8 كلمات في كل لغة — 🔴 **يُعاد تأليفه لا يُترجم حرفيًا** |
| الصوت | 🔴 **راوٍ محلّي** بنفس البطء والنبرة |
| البيئة | محيّدة · بلا معالم بلد |
| الأسماء | تُستبدل محليًا |
| المدد | 🔴 **تُعاد قياسًا لكل لغة** — لا تُنسخ من العربية |

⚠️ **`durationMs` و`autoTurnAfterMs` تختلف بين اللغات** — تُستخرج من ملف كل لغة، ولا تُقدَّر.
