# دليل السلسلة — حكايات قبل النوم

`Series Bible` · `anthology` · 6–8 · `emerging` · الإصدار 1.0

> ⚠️ **هذه السلسلة مسجّلة في قاعدة البيانات بصفر قصص** — ثاني أكبر فراغ بعد كوكب الإيمان والآداب. هذا الدليل والقصص الستّ يملأانه.

---

## 1. الفكرة في جملة

حكاية باثنتي عشرة صفحة لطفل يقرأ بمساعدة، فيها حدث حقيقي يُحلّ قبل النهاية، وتنتهي بسكون.

## 2. مواصفات الوحدة

| الحقل | القيمة |
|---|---|
| الصفحات | **12 بالضبط** |
| المدة | 4:00 – 4:40 |
| الجملة | 🔴 **≤ 12 كلمة** |
| الجمل لكل صفحة | **2–3** |
| السرد | كامل · **والنص معروض معه** |
| الوضع الافتراضي | 🔴 **اقرأ لي** — لا «اقرأ بنفسي» |

| الموسيقى | −22 dB · تنتهي قبل الصفحة 12 |

## 3. 🔴 الفرق عن حكاية هادئة

| البند | حكاية هادئة 3–5 | حكايات قبل النوم 6–8 |
|---|---|---|
| الصفحات | 8 | **12** |
| الجملة | ≤ 8 كلمات | ≤ 12 كلمة |
| النص | للكبير | 🔴 **للطفل** — يقرأ بمساعدة |
| الحدث | تغيّر صغير | 🔴 **حدث حقيقي بعقدة** |
| الخوف | 🔴 ممنوع تمامًا | 🔴 **مسموح ويُحلّ داخل القصة** |
| الشخصيات | 1–2 | 2–3 |
| السرعة | ~90 كلمة/دقيقة | ~100 كلمة/دقيقة |
| الكلمات الجديدة | لا تُحصى | 🔴 **2–3 تُسجَّل** |

🔴 **أهمّ فرق: الخوف مسموح هنا.** طفل السابعة يواجه مخاوف حقيقية *(الرعد، الوحدة، الجديد)*، وقصة تتجاهلها لا تنفعه. **لكن بشرط صارم** في القسم التالي.

## 4. 🔴 قاعدة الخوف — الأهمّ في الدليل

| المرحلة | الصفحات | الحكم |
|---|---|---|
| يظهر الخوف | 4–6 | ✅ مسموح |
| 🔴 **يُحلّ الخوف** | **7–9** | ✅ **إلزامي** |
| الاطمئنان | 10–11 | ✅ إلزامي |
| السكون | 12 | ✅ إلزامي |

### الشروط المطلقة

| # | الشرط |
|---:|---|
| 1 | 🔴 **الخوف يُحلّ قبل الصفحة 10** — لا يبقى للنهاية |
| 2 | 🔴 **يُحلّ داخل القصة** — لا «وفي الغد عرف أنه...» |
| 3 | 🔴 **الحلّ بفهم لا بإنقاذ** — الطفل يفهم فيهدأ |
| 4 | 🔴 **لا خوف من مجهول** — دائمًا له تفسير |
| 5 | 🔴 **لا كائن مخيف** — الخوف من **ظاهرة** لا من شخص |
| 6 | 🔴 **لا خوف من الظلام يُترك بلا معالجة** |
| 7 | 🔴 **الصفحة 12 لا تذكر الخوف أبدًا** |

> 🔴 **الشرط الثالث هو جوهر السلسلة:** الخوف يُحلّ **بفهم** لا بإنقاذ.
>
> «سمعت صوتًا فخافت، **ثم عرفت أنه المطر**» — هذا يعلّم الطفل أن **الفهم يهدّئ**، وهي مهارة يستعملها ليلته كلها.
>
> أما «خافت، **فجاءت أمّها وأنقذتها**» فتعلّمه أن الطمأنينة تحتاج غيره — وهو نائم وحده بعد قليل.
>
> **والأمّ حاضرة، لكنها تُطمئن بالمعلومة لا بالحضور وحده.**

## 6. الشخصيات

| الحقل | القيمة |
|---|---|
| العدد | **2–3** |
| النوع | طفل · أو حيوان مشخَّص · أو الاثنان |
| البالغ | 🔴 **حاضر ودافئ، ويُطمئن بالمعلومة** |
| التنويع | ألوان بشرة وأشكال مختلفة عبر القصص |
| ذوو الإعاقة | يظهرون **كشخصيات عادية** لا كموضوع درس |
| 🔴 الشرّير | **غير موجود** — الصراع مع ظاهرة أو موقف |

🔴 **لا شخصية شرّيرة في السلسلة كلها.** الخوف من الرعد، أو من مكان جديد، أو من الوحدة — **لا من شخص**. شخصية مؤذية قبل النوم تبقى في الغرفة بعد إطفاء الجهاز.

## 7. الكلمات الجديدة

| البند | القاعدة |
|---|---|
| العدد | 🔴 **2–3 لكل قصة** |
| الاختيار | كلمات محسوسة قابلة للتخيّل |
| التقديم | 🔴 **في السياق** — لا تعريف ولا شرح |
| التسجيل | تُسجَّل في بطاقة القصة لتقارير ولي الأمر |
| 🔴 الاختبار | **لا يوجد** — لا سؤال عنها |

🔴 **تُقدَّم في السياق ولا تُشرَح.** «كان الفانوس **صدئًا** من طول السنين» — الطفل يفهم من السياق والصورة. الشرح يقطع القصة ويحوّلها درسًا.

## 8. الراوي

| الحقل | القيمة |
|---|---|
| النبرة | هادئة دافئة · 🔴 **بلا تصعيد في الذروة** |
| السرعة | 🔴 **~100 كلمة/دقيقة** |
| الحجم | ثابت |
| الذروة | 🔴 **تُنطق أهدأ لا أعلى** |
| الصفحات 11–12 | 🔴 **~80 كلمة/دقيقة** — أبطأ |

> 🔴 **الذروة تُنطق أهدأ لا أعلى.** هذا نقيض السرد المعتاد، والسبب أن رفع الصوت في الذروة **يوقظ**. التوتّر يُنقل بالبطء والوقفات لا بالحجم.

| الحقل | القيمة |

🔴 **التشكيل الجزئي إلزامي لمسار `emerging`:** يُشكَّل ما يلتبس فقط *(الفعل المبني للمجهول، والكلمة الجديدة، وما يُغيّر المعنى)*. **التشكيل الكامل يثقل، وغيابه يُفقد القراءة.**

## 10. الترجمة

| البند | القاعدة |
|---|---|
| التصنيف | `translatable` |
| النص | 🔴 **يُعاد تأليفه** بما يحفظ المعنى والإيقاع |
| الكلمات الجديدة | 🔴 **تُختار لكل لغة** — لا تُترجم |
| التشكيل | خاصّ بالعربية · بدائله في كل لغة |
| المدد | تُعاد قياسًا لكل لغة |
| الخوف | 🔴 **يُراجع ثقافيًا** — بعض المخاوف تختلف بين البيئات |

⚠️ **الكلمات الجديدة لا تُترجم.** «صدئ» مناسبة لطفل عربي في السابعة، ومقابلها الحرفي قد يكون شائعًا أو نادرًا جدًا في لغة أخرى. **تُختار كلمات جديدة محليًا** بنفس المعيار.
