# نموذج الصفحة والقراءة — الأساس التقني لكوكب القصص

الإصدار 1.0 · مُشتَقّ من مواصفة المستخدم `كوكب القصص .md` ومُترجَم إلى نموذج إنتاج

> **هذا المستند هو العقد بين المحتوى والتطبيق ولوحة التحكم.** كل قصة في هذا الكوكب تلتزم به حرفيًا.

---

## 1. 🔴 القرار المعماري: النص طبقة مستقلّة

**لا نحفظ الصفحة كصورة تحتوي النص داخلها.**

```
صفحة القصة
├── Artwork Image        ← صورة واحدة مشتركة لكل اللغات
├── Text Layer           ← نص مستقلّ لكل لغة
├── Dialogue Layers      ← فقاعات حوار (للكوميكس)
├── Audio                ← ملف صوت لكل لغة
├── Timing Metadata      ← توقيت الجمل + مدة الصفحة
└── Interactive Regions  ← مناطق قابلة للنقر (اختياري)
```

### ما يمكّنه هذا القرار

| الفائدة | التفصيل |
|---|---|
| تصحيح خطأ لغوي | بلا إعادة رسم الصورة |
| إضافة لغة | نص + صوت فقط · الصورة كما هي |
| تكبير الخطّ | يستجيب لإعدادات الجهاز |
| وضع صديق للديسلكسيا | خطّ بديل بلا إعادة إنتاج |
| تظليل الكلمة مع الصوت | يحتاج نصًا حيًّا لا صورة |
| إخفاء النص | لمن يريد الصور فقط · وللقصة الصامتة |
| 🔴 **نص بلغة وصوت بلغة أخرى** | تعلّم لغة بقصة واحدة |
| تعديل صفحة واحدة | بلا إعادة رفع القصة |

> 🔴 **الفائدة السابعة هي الميزة التنافسية:** نص عربي + صوت إنجليزي *(أو العكس)*. القصة نفسها تصير **أداة تعلّم لغة** بلا إنتاج إضافي. هذا **لا يمكن** لو كان النص محروقًا في الصورة.

## 2. بنية بيانات الصفحة

```json
{
  "pageNumber": 4,
  "image": "page_004.webp",
  "text": {
    "ar": "نظر الطائر إلى السماء، ثم عاد إلى عشّه.",
    "en": "The bird looked at the sky, then returned to its nest.",
    "fr": "L'oiseau regarda le ciel, puis retourna a son nid."
  },
  "audio": {
    "ar": "page_004_ar.m4a",
    "en": "page_004_en.m4a",
    "fr": "page_004_fr.m4a"
  },
  "durationMs": {
    "ar": 5800,
    "en": 5200,
    "fr": 5600
  },
  "dwellMs": {
    "ar": 12000,
    "en": 12000,
    "fr": 12000
  },
  "motion": "kenburns_slow",
  "brightness": 0.85
}
```

| الحقل | الوصف | إلزامي |
|---|---|---|
| `pageNumber` | ترتيب الصفحة | ✅ |
| `image` | صورة واحدة لكل اللغات | ✅ |
| `text` | نص لكل لغة | ✅ للعربية |
| `audio` | ملف صوت لكل لغة | ✅ للعربية |
| `durationMs` | **مدة السرد الفعلية فقط — تُستخرج تلقائيًا من ملف الصوت، لا تشمل وقت التأمل** | ✅ |
| `dwellMs` | **وقت تأمل الصورة بعد انتهاء السرد — مؤلف لكل صفحة (ms). لا يُحرق في الـWAV** | ✅ في مسار النوم؛ اختياري نهارًا (fallback صغير) |
| `motion` | حركة الكاميرا | ✅ |
| `brightness` | 🔴 سطوع الصفحة — **ينخفض تدريجيًا** | ✅ في مسار النوم |

> **القاعدة الذهبية — لا تخلط المفهومين:**
> - `durationMs` = طول ملف الصوت الحقيقي فقط. لا يُمدد صناعيًا.
> - `dwellMs` = وقت بقاء الصفحة ظاهرة بعد انتهاء السرد ليتأمل الطفل الرسم قبل التقليب التلقائي.
> - `estimatedExperienceMs` (مشتق، لا يُخزن) = `durationMs + dwellMs + transition` — يُحسب للتقارير فقط.
> - `autoTurnAfterMs` القديم موقف — لا يُخزن. وقت التقليب = حدث اكتمال الصوت الحقيقي → `dwellMs` → انتقال.

🔴 **`brightness` حقل خاصّ بهذا الكوكب**، ولا يوجد في الكواكب الأخرى. انظر [منحنى السطوع](#5--منحنى-السطوع-والهبوط).

## 3. مزامنة الصوت والتقليب

### التقليب التلقائي — نموذج dwell

```
حدث اكتمال السرد الحقيقي (audio completion event)
    ↓
dwellMs — وقت تأمل الصورة (مؤلف لكل صفحة، مثلاً 8–18ث)
    ↓
انتقال (animation — إعداد واجهة، لا بيانات محتوى)
    ↓
الصفحة التالية
```

| البند | القيمة | أين يُخزن |
|---|---|---|
| `durationMs` | مدة السرد الفعلية — من الملف | `story_pages.duration_ms` / `story_page_localizations` لاحقًا |
| `dwellMs` | وقت التأمل بعد السرد — مؤلف لكل صفحة | `story_pages.dwell_ms` (nullable) |
| `estimatedExperienceMs` | `durationMs + dwellMs` — مشتق | **لا يُخزن**، يُحسب للتقارير |
| مدة الانتقال | إعداد واجهة (مثلاً 280ms) | `PageController` / `Theme` — ليس بيانات قصة |

🔴 **مصدر الحقيقة هو حدث اكتمال الصوت الحقيقي، لا عدّ تنازلي من `durationMs` المقدر.** حتى لو اختلف طول الملف الفعلي عن الرقم المخزن، التقليب يبدأ بعد انتهاء التشغيل الحقيقي.

🔴 **مسار النوم يستعمل dwell أطول (12–18ث).** التقليب السريع ينبّه، والبطيء يهدّئ — هذا ليس تفصيلًا جماليًا بل **أداة تهدئة**.

> لا تُخزن مدة الانتقال في كل صفحة. ولا تستخدم أرقامًا سحرية (`+900`/`+400`) داخل widgets بلا تسمية.

**والانتقال `Dissolve` ناعم لا `Page Curl` ثقيل.** التقليب الورقي الثقيل طوال القصة يشتّت ويثقل الأجهزة الضعيفة، ويُعطَّل من الإعدادات.

### توقيت الجمل — لوضع «اقرأ معي»

```json
{
  "page": 5,
  "audio": "page_005_ar.m4a",
  "durationMs": 13200,
  "dwellMs": 12000,
  "sentences": [
    { "textId": "s1", "startMs": 0,    "endMs": 5300  },
    { "textId": "s2", "startMs": 5300, "endMs": 13200 }
  ]
}
```

> 🔴 **لا `autoTurnAfterMs` في البيانات.** وضع «اقرأ معي» يُظلّل الجملة بحسب `sentences`، ثم — عند **اكتمال الصوت فعليًا** — يبدأ `dwellMs`، ثم الانتقال. توقيت الجمل لا يُستخدم للتقليب، بل للتظليل فقط.

| المرحلة | الدقّة |
|---|---|
| الأولى | 🔴 **صوت واحد لكل صفحة** — بلا توقيت جمل |
| الثانية | **توقيت الجملة** → تظليل الجملة الحالية |
| الثالثة | توقيت الكلمة → تظليل كل كلمة |

> 🔴 **المرحلة الأولى بلا توقيت جمل، وهذا قرار مقصود.** توقيت الجمل يحتاج محرّر `Waveform` وعملًا يدويًا لكل صفحة بكل لغة. البدء بصوت الصفحة كاملًا **أبسط وأثبت**، ويكفي لوضعَي «اقرأ لي» و«اقرأ بنفسي».
>
> **`timing_cues` في `story_page_localizations` يبقى `NULL` في المرحلة الأولى** — والحقل موجود جاهزًا للثانية.

## 4. أوضاع القراءة الأربعة

| الوضع | الصوت | التقليب | النص | المسار |
|---|---|---|---|---|
| **اقرأ بنفسي** | بالنقر على جملة فقط | يدوي | يُظهر / يُخفى | `emerging`+ |
| **اقرأ لي** | تلقائي | 🔴 **تلقائي** | يُظهر / يُخفى | كل الأعمار |
| **اقرأ معي** | تلقائي | تلقائي | 🔴 **الجملة تُظلَّل** | `emerging`+ · المرحلة 2 |
| **قصة صامتة** | لا صوت | يدوي | 🔴 **لا نص** | كل الأعمار · المرحلة 2 |

### القواعد المشتركة

| القاعدة | التفصيل |
|---|---|
| نافذة الاختيار | تظهر **عند بدء القصة** لا في الإعدادات |
| التقليب اليدوي أثناء «اقرأ لي» | 🔴 **مسموح** — الصوت ينتقل للصفحة الجديدة |
| إيقاف التقليب التلقائي | 🔴 **متاح دائمًا** للطفل |
| العودة لصفحة سابقة | يُعاد تشغيل صوتها |
| سرعة الراوي | قابلة للتعديل **ضمن حدود** — لا تسريع مشوّه |

### 🔴 الافتراضي بحسب العمر

| المسار | الافتراضي | السبب |
|---|---|---|
| `preschool` 3–5 | **اقرأ لي** | لا يقرأ · السرد كامل إلزامي |
| `kids` 6–8 | **اقرأ لي** | يقرأ بمساعدة · والنوم ليس وقت جهد قراءة |

🔴 **«اقرأ بنفسي» ليس الافتراضي في مسار النوم ولو كان الطفل يقرأ.** القراءة الذاتية جهد ذهني، ووقت النوم ليس وقته. تبقى **متاحة** لمن يريدها نهارًا.

## 5. 🔴 منحنى السطوع والهبوط

خاصّية تميّز هذا الكوكب: **الصفحة الأخيرة أخفت من الأولى.**

| موضع الصفحة | `brightness` | الحركة | ملاحظة |
|---|---:|---|---|
| الأولى | 1.00 | `kenburns_slow` | الاستقبال |
| الثلث الأول | 0.95 | `kenburns_slow` | التعريف |
| الثلث الثاني | 0.90 | `pan_slow` | 🔴 **الذروة هنا** |
| بداية الثلث الأخير | 0.85 | `kenburns_slow` | الحلّ |
| قبل الأخيرة | 0.78 | `static` | 🔴 هبوط |
| **الأخيرة** | **0.70** | 🔴 **`static`** | سكون تام |

### القواعد

| # | القاعدة |
|---:|---|
| 1 | 🔴 **الذروة في الثلث الثاني** — لا في الأخير |
| 2 | 🔴 **الصفحتان الأخيرتان بلا حركة كاميرا** (`static`) |
| 3 | 🔴 السطوع **ينزل ولا يعود** |
| 4 | 🔴 الصفحة الأخيرة **بلا حدث** — وصف سكون فقط |
| 5 | الموسيقى **تخفت** مع السطوع، وتنتهي **قبل** آخر جملة |

> 🔴 **«الصفحة الأخيرة بلا حدث» قاعدة تحريرية لا تقنية.** كل قصة في هذا الكوكب تنتهي بصفحة **وصف سكون**: نائم · هادئ · مطمئنّ. لا مفاجأة، ولا سؤال، ولا تمهيد لقصة قادمة.
>
> **والحركة تتوقّف قبل السطوع** — لأن الحركة تنبّه أكثر من الضوء.

## 6. 🔴 مسار ما قبل النوم

مسار عرض خاصّ يُفعَّل من إعدادات ولي الأمر أو تلقائيًا بحسب الوقت.

| البند | السلوك في المسار |
|---|---|
| Autoplay | 🔴 **معطّل تمامًا** |
| «القصة التالية» | 🔴 **لا تظهر** |
| توصيات بعد القصة | 🔴 **لا تظهر** |
| الألعاب | 🔴 **لا تظهر** |
| أسئلة الفهم | 🔴 **لا تظهر** |
| شارات وإنجازات | 🔴 **لا تظهر** |
| مؤقّت النوم | ✅ 10 · 20 · 30 دقيقة |
| السطوع | ينخفض بمنحنى الصفحات |
| شاشة الإتمام | 🔴 **«تصبح على خير» وانتهى** |

> 🔴 **شاشة الإتمام في مسار النوم لا تحتوي أي زرّ يقود لمحتوى آخر.**
>
> جملة واحدة، ثم عودة تلقائية لشاشة هادئة أو إطفاء. **كل زرّ إضافي هو دعوة للسهر.**
>
> **وهذا ينقض نمط `Streaming` المعتاد عن قصد.** المنصّة تُبقي المشاهد في الكواكب الأخرى، **وتُخرجه** في مسار النوم. اختلاف السلوك مقصود ومصمَّم.

### الألعاب — قرار الفصل

| السياق | الحزمة |
|---|---|
| مسار ما قبل النوم | 🔴 **لا تظهر إطلاقًا** |
| قسم «قصص» نهارًا | ✅ تظهر بعد القصة |
| قسم الألعاب المستقلّ | ✅ متاحة دائمًا |

**التهدئة عمل من عشر دقائق، وتُهدَم بشاشة تفاعلية في ثلاثين ثانية.** ولذلك لكل قصة حزمة، ولا تُعرض في وقتها الخطأ.

## 7. تجربة الأجهزة

### الموبايل

| البند | السلوك |
|---|---|
| العرض | صفحة واحدة كاملة |
| التقليب | سحب **من اليمين لليسار** في العربية · عكسه في LTR |
| بديل السحب | نقر على جوانب الشاشة · أزرار التالي والسابق |
| الأدوات | في الأسفل · تختفي أثناء القراءة |
| الانتقال | `Dissolve` أو `Slide` ناعم 250–400ms |

### التابلت

| الوضع | السلوك |
|---|---|
| رأسي | صفحة واحدة · نص واضح · أدوات أسفل |
| أفقي | 🔴 **صفحتان متقابلتان** · تقليب من المنتصف |
| أفقي بديل | صورة على صفحة ونص على الأخرى |
| «اقرأ لي» أفقي | ينتقل تلقائيًا بين الصفحتين ثم يقلّب |
| القلم | مدعوم في أنشطة النهار فقط |

### التلفزيون

| الوضع | التقليب |
|---|---|
| **شاهد القصة** | 🔴 تلقائي |
| **اقرأ لي** | تلقائي مع نص |
| **تحكّم يدوي** | بالريموت |
| **استماع فقط** | غلاف + خلفية هادئة + مؤقّت نوم |

**الريموت:**

| الزرّ | الوظيفة |
|---|---|
| يمين / يسار | الصفحة التالية والسابقة |
| OK | تشغيل / إيقاف |
| أعلى | أدوات القراءة |
| أسفل | شريط الصفحات |
| Back | خروج **مع حفظ التقدّم** |
| OK مطوّل | إعدادات الصوت واللغة |

🔴 **على التلفزيون لا تُعرض القصة كـPDF**، بل **عرض قصصي سينمائي**: حركة كاميرا بطيئة، وظهور نصّ تدريجي، وانتقال `Dissolve`.

**لكن في مسار النوم:** الحركة **تتوقّف** في الصفحتين الأخيرتين، والسطوع ينخفض — كما في الموبايل.

## 8. الحركة السينمائية — حدودها

| الحركة | الاستخدام | الحدّ |
|---|---|---|
| `kenburns_slow` | تكبير بطيء جدًا | ≤ 4% في 10 ثوان |
| `pan_slow` | تحريك أفقي | ≤ 6% في 10 ثوان |
| `static` | 🔴 بلا حركة | الصفحتان الأخيرتان |
| `parallax` | طبقات — إن توفّرت | ⏳ المرحلة 2 |
| ظهور النص | تدريجي | ≤ 600ms |

🔴 **ممنوع في مسار النوم:** وميض · مؤثّرات جسيمات كثيفة · تكبير سريع · اهتزاز · أي حركة > 6%.

**ومؤثّرات الجوّ الخفيفة مسموحة** *(مطر هادئ، أوراق، نجوم تلمع ببطء)* بشرط **≤ 3Hz** وبلا تغيّر سطوع مفاجئ.

> **لا نحوّل القصة إلى `Animation` كامل.** `Motion Storybook` خفيف يحفظ تكلفة الإنتاج ويكفي للتجربة.

## 9. الكوميكس — للمرحلة الثانية

```
Comic
└── Page
    ├── Panel 1
    │   ├── Coordinates  (x, y, w, h)
    │   ├── Dialogue     (per language)
    │   └── Audio        (per language)
    ├── Panel 2
    └── Panel 3
```

| الوضع | السلوك |
|---|---|
| صفحة كاملة | الطفل يرى الصفحة ويكبّرها يدويًا |
| **لوحة بلوحة** | تكبير اللوحة → تشغيل الحوار → ظهور الفقاعة → انتقال ناعم |

🔴 **لا كوميكس في مسار ما قبل النوم.** التكبير والانتقال بين اللوحات نشاط بصري منبّه، ومكانه النهار.

## 10. 🔴 قاعدة الخيال والعلم

مشكلة حقيقية في هذا الكوكب: قصة خيالية قد **تنقض** حلقة في كوكب علوم.

| المثال | التعارض | الحلّ المعتمد |
|---|---|---|
| «القمر ينام» | [أطوار القمر](../03-oloom/science-in-a-minute/ep-03-moon-phases.md) تقول إن القمر لا يتغيّر | 🔴 **صيغة تشبيه صريحة** + ملاحظة في دليل ولي الأمر |
| «النملة تتكلّم» | لا تعارض — تشخيص مقبول | مقبول بلا شرط |
| «النجمة تائهة» | الفلك: النجوم لا تتحرّك بيننا | 🔴 صيغة تشبيه + ملاحظة |
| «المطر يغنّي» | لا تعارض — استعارة | مقبول |

### القاعدة

| النوع | الحكم |
|---|---|
| **تشخيص** *(حيوان يتكلّم)* | ✅ مقبول — الطفل يعرف أنه خيال |
| **استعارة** *(المطر يغنّي)* | ✅ مقبول |
| 🔴 **دعوى تُشبه حقيقة علمية** | ⚠️ تحتاج **صيغة تشبيه صريحة** |
| 🔴 **نقض مباشر لحلقة علمية** | ❌ **مرفوض** |

**صيغة التشبيه الصريحة:** «**كأنّ** القمر ينام» · «**تبدو** النجمة تائهة» — لا «القمر نام».

🔴 **وكل قصة فيها دعوى كهذه تحمل في دليل ولي الأمر سطرًا يذكر الحقيقة العلمية ويربط بالحلقة.** هذا يجعل القصة **مدخلًا** للعلم لا عقبة أمامه.

## 14. معايير القبول — لكل قصة

- [ ] 🔴 **النص طبقة مستقلّة** — لا نصّ محروق في أي صورة.
- [ ] صورة **واحدة** لكل صفحة مشتركة بين اللغات.
- [ ] نص وصوت **لكل لغة منشورة**.
- [ ] `durationMs` مستخرجة من الملف الفعلي — **مدة السرد فقط**.
- [ ] 🔴 **`dwellMs` مؤلَّف لكل صفحة** — وقت تأمل الرسم بعد انتهاء السرد *(هادئة ونوم: 8–18ث بحسب كثافة الصورة)*.
- [ ] 🔴 **التقليب يبدأ من حدث اكتمال الصوت الحقيقي** ثم `dwellMs` — لا عدّ تنازلي من `durationMs`، ولا `+900/+1000ms` داخل الـwidget.
- [ ] 🔴 `estimatedExperienceMs` *(مشتق، لا يُخزن)* = `Σ durationMs + Σ dwellMs (ما قبل الأخيرة) + (الصفحات−1) × مدة الانتقال` **داخل مدى السلسلة التحريري**.
- [ ] الانتقال حركة واجهة ناعمة *(`Dissolve`)* — **لا تُخزن مدته في بيانات الصفحة**.
- [ ] 🔴 **منحنى السطوع** مطبَّق: من 1.00 إلى 0.70.
- [ ] 🔴 **الذروة في الثلث الثاني** لا الأخير.
- [ ] 🔴 **الصفحتان الأخيرتان `static`** بلا حركة.
- [ ] 🔴 **الصفحة الأخيرة بلا حدث** — وصف سكون.
- [ ] الموسيقى تنتهي **قبل** آخر جملة.
- [ ] 🔴 **لا Autoplay · لا قصة تالية · لا توصيات · لا ألعاب · لا أسئلة · لا شارات** في مسار النوم.
- [ ] 🔴 **مؤقّت نوم** متاح.
- [ ] 🔴 **لا وميض · لا صوت مفاجئ · لا حركة > 6%**.
- [ ] 🔴 **لا خوف بلا حلّ** داخل القصة.
- [ ] الافتراضي **«اقرأ لي»** في كلا المسارين.
- [ ] التقليب اليدوي **مسموح** أثناء «اقرأ لي».
- [ ] `timing_cues` = `NULL` في المرحلة الأولى *(الحقل موجود)*.
- [ ] 🔴 **قاعدة الخيال والعلم** مطبَّقة، وصيغة التشبيه صريحة عند اللزوم.
- [ ] دليل ولي الأمر يذكر الحقيقة العلمية عند وجود دعوى.
- [ ] اتجاه السحب صحيح في RTL و LTR.
- [ ] معاينة على **ثلاثة أجهزة** موثّقة.
- [ ] 🔴 **مراجعة نوم** موقّعة.
- [ ] 🔴 **مراجعة لغوية** و**مراجعة صوتية** موقّعتان.
