# كوكب القصص — Planet Qisas

> **المعرف:** `qisas` | **اللون:** `#9D68FF` / `#FF6FAE` | **الأيقونة:** `assets/images/planets/planet-stories.png` (1.00MB, 57.3% شفاف, 907x984)
> **الاسم:** `كوكب القصص` | **الوصف:** حكايات دافئة قبل النوم وفي كل وقت

## الفكرة
عالم الحكايات المصورة والمسموعة للأطفال 3-12 سنة. كل قصة = رحلة قصيرة بهدف واضح (قيمة/مهارة/معلومة) وتنتهي بسؤال أو نشاط. لا يوجد ترتيب إلزامي - كل قصة مستقلة.

## المسارات العمرية

| المسار | العمر | الطول | النمط | الصوت | التفاعل |
|---|---|---|---|---|---|
| `preschool` | 3-5 | 60-180 كلمة | صور كبيرة 70%، نص 30% | `اقرأ لي` افتراضي، `اقرأ بنفسي` اختياري | `tap` - ضغطة واحدة تكمل |
| `kids` | 6-8 | 250-500 كلمة | توازن صورة/نص، حوار | `اقرأ بنفسي` افتراضي، `اقرأ لي` متاح | `guided` - سؤال تفاعلي واحد |
| `junior` | 9-12 | 500-1000 كلمة | كوميكس `Panel-by-Panel`، نص أكثر | `اقرأ بنفسي` فقط | `mixed` - اختيار مسار + مشروع صغير |

## سلسلة الحالية

* `bedtime-stories` (3-8 سنوات, 12 حلقة) - حكايات هادئة وصور حالمة - `status: published` - المراجعات مكتملة

## خط أنابيب الإنتاج

```
فكرة -> نص (60/250/500 كلمة) -> مراجعة لغوية -> مراجعة تربوية -> ستوري بورد -> رسم -> صوت (اقرأ لي) -> تجميع -> QA عمر -> نشر
```

* كل نص يمر بـ `review_lang` (لغة عربية سليمة) و `review_edu` (هدف تربوي واضح) قبل الرسم
* `visual_style_id` محدد لكل قصة - لا يخلط رسوم `preschool` الناعمة مع `junior` التفصيلية

## القياس والإتقان

| المقياس | كيف يحسب | أين يحفظ |
|---|---|---|
| `قراءة مكتملة` | وصل لآخر صفحة | `FamilyState.content_progress (completed=1)` |
| `إعادة قراءة` | فتح نفس القصة مرة ثانية | `attempts` + `mastery` |
| `تفاعل` | ضغط/اختيار/سؤال | `attempts.answers_json` |
| `استماع` | شغل `اقرأ لي` حتى النهاية | `content_progress + audio` |
| `إتقان` | `correct_attempts >=3` -> `independent` | `mastery.level` |

> كل حدث يحمل `child_id + event_id` لعزل الأطفال وعدم خلط الدرجات.
