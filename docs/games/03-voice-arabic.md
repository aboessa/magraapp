# 03 — مواصفة الصوت العربي

## المبادئ الحاكمة

| # | المبدأ |
|---:|---|
| 1 | **الصوت هو الواجهة الأساسية للبراعم.** أي لعبة لا تُلعب بالصوت وحده في `preschool` تُعدّ **غير مكتملة** ولا تُنشر |
| 2 | **فصحى مبسطة** عند الإطلاق. لا لهجة محلية في الإصدار الأول لأنها تقسّم الجمهور العربي |
| 3 | **معلّق بشري.** لا صوت اصطناعي في نسخة منشورة دون مراجعة وحقوق وموافقة موثقة |
| 4 | **لا صوت مفاجئ** ولا عالٍ للبراعم. الموسيقى لا تطغى على الكلام أبدًا (−18 dB تحته) |
| 5 | **زر «اسمع مرة أخرى» ظاهر في كل لعبة، بلا استثناء** |
| 6 | مفاتيح الصوت **دلالية** لا نصية، حتى لا تنكسر عند الترجمة |

## السرعة والنبرة وطول الجملة

| المسار | السرعة | النبرة | طول الجملة | ملاحظة |
|---|---|---|---|---|
| `preschool` | بطيئة، وقفات واضحة | دافئة، مرحة، هادئة | ≤ 6 كلمات | التكرار مقبول ومفيد |
| `kids` | متوسطة | ودّية، متحمسة قليلًا | ≤ 12 كلمة | |
| `junior` | طبيعية | **محترمة، غير طفولية** | ≤ 20 كلمة | التصغير يُنفّرهم |

## بديل الصوت — إلزامي

الطفل قد يكون أصمّ، أو في مكان صامت، أو الجهاز مكتوم:

- كل تعليمة صوتية لها **رمز بصري متحرك** يوضح الحركة المطلوبة.
- النجاح والخطأ يظهران بصريًا (توهج / ارتداد) لا بالصوت فقط.
- `rhythm_tap` يعرض النبضة بصريًا وباهتزاز.
- **لا لعبة يعتمد الفوز فيها على تمييز صوتي وحده**، إلا `word_build` وفيها زر «اعرض الكلمة مكتوبة».

## متطلبات التسجيل الإنتاجي

| البند | المواصفة |
|---|---|
| صيغة المصدر | WAV 48kHz 24-bit |
| صيغة التوزيع | AAC 128kbps mono |
| مستوى الصوت | ‎−16 LUFS للكلام |
| الصمت الطرفي | ≤ 150ms |
| أرقام العدّ | **مقاطع منفصلة** لكل رقم 1–20 |
| أصوات الحروف | مقطع لكل حرف بكل شكل مستخدم |
| الحقوق | عقد معلّق موثق + إقرار استخدام تجاري |

### لماذا مقاطع العدّ منفصلة

المحرك ينطق الأرقام **بالتتابع مع إبراز كل عنصر** أثناء العدّ التصحيحي، ولا يمكن استخدام جملة واحدة مسجّلة مسبقًا.

## سلوك طبقة الصوت المشتركة

| السلوك | المتطلب |
|---|---|
| التحميل المسبق | كل أصوات المستوى قبل بدايته |
| الإيقاف | إيقاف فوري عند الخروج أو تبديل الطفل |
| كتم الجهاز | احترامه؛ والبديل البصري يعمل |
| التزامن | لا تراكب لمقطعين كلاميين أبدًا |
| قائمة الانتظار | التعليمة تُقطع عند لمس المستخدم لعنصر |
| إعادة المحاولة | فشل تحميل أصل صوتي لا يوقف اللعبة |
