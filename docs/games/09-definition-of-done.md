# 09 — تعريفات «مكتمل»

## المحرك

- [ ] يُلعب **بالصوت وحده** في `preschool`، وبالبديل البصري كاملًا.
- [ ] يجتاز تحقق Schema لكل حزمة ([02](./02-data-contract.md)).
- [ ] **الطفل لا يعلق فيه أبدًا** — سلّم الفشل الخمسي مطبَّق عبر الطبقة المشتركة ([04](./04-encouragement-and-failure.md)).
- [ ] لا يحتوي منطق تشجيع أو مساعدة خاصًا به.
- [ ] يكتب `attempts` صحيحًا بـ`event_id` ثابت وIdempotency مثبتة ([05](./05-mastery-and-measurement.md)).
- [ ] يعمل في RTL وLTR بلا انعكاس خاطئ (جدول الاتجاه في [01](./01-localization-i18n.md)).
- [ ] يجتاز كل متطلبات [06 — إمكانية الوصول](./06-accessibility.md).
- [ ] بديل السحب موجود إن استخدم السحب.
- [ ] `engine_version` و`pack_version` مثبتان، والحزم القديمة تعمل.
- [ ] لا نص مكتوب داخل أي صورة واجهة.
- [ ] `supports_dpad` صحيح، أو مخفي على TV صراحة.
- [ ] لا مؤقت في أي حزمة `preschool`.

## الحزمة

- [ ] مراجعة تربوية ولغوية وعمرية موثقة.
- [ ] مراجعة علمية لـ`sim_lab`، تاريخية لـ`timeline_map`، لغوية معتمدة لـ`word_build` و`trace_color` (الحروف).
- [ ] كل المفاتيح الصوتية الإلزامية مسجّلة ([03](./03-voice-arabic.md)).
- [ ] حقوق كل أصل موثقة: صور، موسيقى، خطوط، صوت.
- [ ] `age_min/age_max` و`reading_level` و`interaction_mode` و`supervision_level` محددة.
- [ ] `safety_notes` غير فارغة لأي نشاط منزلي، و`supervision_level = required`.
- [ ] الحزمة `language_specific` **مؤلَّفة** لا مترجمة (`translated_from = NULL`).
- [ ] كل أصل `ready` في `content_assets`.
- [ ] خمسة مستويات بتدرّج موثق.
- [ ] عدد العناصر في كل مستوى ≤ `max_elements_on_screen`.

## التجربة كاملة

- [ ] 12 محركًا × 3 حزم = 36 لعبة تعمل.
- [ ] كل مسار عمري له 4 محركات على الأقل.
- [ ] محركان ترفيهيان بلا قياس تعليمي (`memory_flip`, `rhythm_tap`).
- [ ] لوحة ولي الأمر تعرض `mastery` بلغة وصفية لا بعدّ أخطاء.
- [ ] لا إعلانات ولا مشتريات داخل الألعاب.
- [ ] لا leaderboard ولا مقارنة بأطفال آخرين.
- [ ] المكافآت المكتسبة لا تُفقد أبدًا.
- [ ] كل الألعاب تعمل في `ar`، والمستقلة عن اللغة جاهزة لـ`en`.

## بوابة QA الرباعية لكل حزمة

| النوع | الفاحص | المعيار |
|---|---|---|
| تقني | مهندس | تحقق Schema، لا أعطال، الأصول تُحمَّل |
| تعليمي | مراجع تربوي | الهدف يُقاس فعلًا، التدرّج منطقي |
| عُمري | QA أطفال بموافقة ولي الأمر | مفهوم، غير مخيف، غير محبط |
| إمكانية وصول | مراجع إمكانية وصول | [06](./06-accessibility.md) بالكامل |

## ما لا يعتبر «مكتملًا»

| الحالة | السبب |
|---|---|
| لعبة تعمل لكن لا تُلعب بالصوت وحده في `preschool` | مخالفة المبدأ الأول |
| محرك يحتوي عبارات تشجيع مكتوبة داخله | يكسر الطبقة المشتركة |
| حزمة بأصل واحد غير موثق الحقوق | خطر قانوني |
| محرك يعلق الطفل بعد 5 محاولات | مخالفة سياسة الفشل |
| صورة تحتوي نصًا عربيًا مطبوعًا | يمنع الإطلاق العالمي |
| `word_build` بالإنجليزية مترجمة آليًا من العربية | خطأ تعليمي |
