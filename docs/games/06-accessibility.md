# 06 — إمكانية الوصول

## المتطلبات العامة

| المتطلب | القيمة |
|---|---|
| هدف اللمس | ≥ 48dp، و**≥ 64dp** في `preschool` |
| تباين النص | ≥ 4.5:1، والعناصر الكبيرة ≥ 3:1 |
| المعلومة باللون | **ممنوع** الاعتماد على اللون وحده؛ يُضاف شكل أو نقش أو رمز |
| `TextScaler` | يعمل حتى 2.0× بلا قطع نص |
| الحركة | احترام «تقليل الحركة»؛ بديل ثابت لكل انتقال |
| الوميض | **ممنوع** أي وميض > 3Hz |
| المؤقتات | لا مؤقت في `preschool`؛ قابل للتمديد في غيره |
| قارئ الشاشة | ترتيب قراءة منطقي في RTL وLTR، ووصف بديل لكل صورة |
| TV/D-pad | كل لعبة إما تعمل بالـD-pad أو **تُخفى على TV صراحة** |
| اليد اليسرى | العناصر التفاعلية لا تُثبَّت في جهة واحدة |
| بديل السحب | **إلزامي** في كل محرك يستخدم السحب: لمس ثم لمس |

## بديل السحب — إلزامي في كل محرك

| المحرك | البديل |
|---|---|
| `match_pairs` | لمس العنصر ← لمس الهدف |
| `trace_color` | لمس النقاط بالتتابع |
| `sort_bins` | لمس العنصر ← لمس السلة |
| `count_quantity` | لمس العنصر ← لمس الصندوق |
| `sequence_order` | لمس اللوحة ← لمس الخانة |
| `word_build` | لمس الحرف ← لمس الخانة |
| `block_code` | لمس البلوك ← لمس موضع الإدراج |
| `sim_lab` | أزرار +/− بدل المنزلق |
| `timeline_map` | لمس العنصر ← لمس الموضع + أزرار تحريك دقيق |

`memory_flip`, `rhythm_tap`, `logic_pattern` تستخدم `tap` فقط أصلًا.

## أوضاع مبسّطة إلزامية

| المحرك | الوضع المبسّط |
|---|---|
| `trace_color` | هامش انحراف 40dp، تغطية 60%، لمس نقاط بالتتابع |
| `rhythm_tap` | مسار واحد، `hit_window_ms = 500` |

هذان المحركان يحتاجان دقة حركية، فبدون الوضع المبسّط يُستبعد أطفال ذوو صعوبات حركية.

## دعم TV

| المحرك | D-pad | ملاحظة |
|---|---|---|
| `trace_color` | ❌ | **يُخفى على TV** — التتبّع يحتاج لمسًا |
| الباقي (11 محركًا) | ✅ | مدعوم |

قاعدة: `supports_dpad: false` ⇒ اللعبة لا تظهر في كتالوج TV إطلاقًا، ولا تظهر ثم تفشل.

## اللون والتمييز

| الحالة | المطلوب |
|---|---|
| صحيح / خطأ | **لا** يُدلّ عليه بالأحمر/الأخضر وحدهما؛ يُضاف رمز وحركة |
| سلات `sort_bins` | صورة + نص + صوت، لا لون فقط |
| أشكال `logic_pattern` | شكل + **نقش**، لا لون فقط |
| المشتّتات | لا تُميَّز باللون وحده |
| النبضة في `rhythm_tap` | توهج ناعم لا وميض |

## قارئ الشاشة

| العنصر | المطلوب |
|---|---|
| كل صورة | وصف بديل نصي مترجم |
| كل خلية شبكة | وصف موضعها ومحتواها |
| كل موضع في `timeline_map` | وصف نصي («القرن الثامن الميلادي») |
| جدول نتائج `sim_lab` | متاح **نصيًا** لا رسمًا بيانيًا فقط |
| ترتيب التنقل | منطقي في RTL وLTR |

## الحركة والوميض

- كل انتقال له بديل ثابت عند تفعيل «تقليل الحركة».
- `memory_flip`: حركة القلب تُختصر.
- `sim_lab`: الرسوم المتحركة تُختصر مع بقاء النتيجة النصية.
- **ممنوع** أي وميض يتجاوز 3Hz في أي محرك.

## معايير القبول

- [ ] كل محرك يجتاز جدول المتطلبات العامة.
- [ ] بديل السحب يعمل في كل محرك يستخدم السحب.
- [ ] الوضعان المبسّطان يعملان.
- [ ] `trace_color` مخفي على TV.
- [ ] لا اعتماد على اللون وحده في أي مكان.
- [ ] `TextScaler = 2.0` بلا قطع نص في أي شاشة لعبة.
- [ ] وصف بديل لكل صورة، مترجم لكل لغة.
- [ ] لا وميض > 3Hz.

## ملاحظة على التوافق مع WCAG

التحقق الكامل من مطابقة WCAG يتطلب **اختبارًا يدويًا بتقنيات مساعدة حقيقية ومراجعة خبير إمكانية وصول**. هذه القائمة تغطي المتطلبات المعروفة والقابلة للفحص آليًا أو بمراجعة منظمة، ولا تُغني عن ذلك الاختبار.
