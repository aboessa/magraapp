# 11 — `sim_lab` · مختبر محاكاة

## الهوية

| الحقل | القيمة |
|---|---|
| `engine_id` | `sim_lab` |
| المسار الأساسي | `junior` |
| التصنيف اللغوي | `language_neutral` (التسميات مترجمة) |
| المدخلات | `drag` (منزلقات), `tap` |
| مؤقت | ❌ لا |
| `max_elements_on_screen` | 6 |
| هدف اللمس | 48dp |
| `supports_dpad` | ✅ |
| الهدف التعليمي | المنهج العلمي: فرضية ← تجربة ← تفسير |
| الإشراف | `recommended`، و`required` لأي تجربة منزلية |

## القواعد — ثلاث مراحل إلزامية

| المرحلة | ما يفعله الطفل |
|---:|---|
| 1. **توقّع** | يختار فرضية **قبل** التجربة |
| 2. **جرّب** | يحرّك متغيرًا ويشاهد النتيجة، ويعيد بقيم مختلفة |
| 3. **فسّر** | يختار التفسير الصحيح للنتيجة |

> **قرار تربوي حاسم:** التوقع الخاطئ **ليس فشلًا** ولا يُخصم. يُسجَّل كتعلّم. **التفسير** هو ما يُقاس.

## شرط الفوز

إكمال المراحل الثلاث مع تفسير صحيح.

## سلوك الخطأ

| الحالة | السلوك |
|---|---|
| توقع خاطئ | «لنرَ ما سيحدث فعلًا.» — **بلا أي سلبية** |
| تفسير خاطئ (1) | «قارن نتيجتك عند ساعتين وعند ست ساعات.» |
| تفسير خاطئ (2) | إبراز جدول النتائج المسجّلة |
| تفسير خاطئ (3) | استبعاد خيار |
| تفسير خاطئ (4) | شرح كامل مع ربطه بالبيانات |

## المحاكاة المدعومة عند الإطلاق

| `sim` | المتغيرات | العلاقة |
|---|---|---|
| `plant_growth` | ساعات الضوء، كمية الماء | طردية ثم تشبّع |
| `circuit` | عدد البطاريات، عدد المصابيح | طردية / عكسية |
| `pendulum` | الطول، الكتلة | **الطول يؤثر، الكتلة لا** |

`pendulum` مهمة تربويًا لأنها تعلّم أن **متغيرًا قد لا يكون له تأثير** — مفهوم يصعب تعليمه بغير المحاكاة.

## المستويات الخمسة

| المستوى | المتغيرات | المطلوب |
|---:|---:|---|
| 1 | 1 | توقّع + تجربة + تفسير |
| 2 | 1 | + قراءة جدول نتائج |
| 3 | 2 | تثبيت متغير وتغيير آخر |
| 4 | 2 | التعرف على علاقة عكسية أو منعدمة |
| 5 | 2–3 | تصميم التجربة: يختار ما يثبّت وما يغيّر |

| `vo.instruction` | «اتبع المراحل الثلاث: توقّع، جرّب، فسّر.» |
| `vo.instruction_repeat` | نفس النص |
| `vo.stage_predict` | «قبل أن نجرّب، ما توقعك؟» |

## الأصول

- رسوم محاكاة متحركة لكل `sim`.
- منزلقات وجدول نتائج.
- شرح صوتي لكل تفسير.
- **مراجعة علمية إلزامية** لكل محاكاة قبل النشر.

## حزم الإطلاق الثلاث

| الحزمة | العنوان | الفئة | إشراف |
|---|---|---|---|
| `sl-plant` | ماذا تحتاج النبتة؟ | 9–11 | `none` |
| `sl-circuit` | دائرة تُضيء | 10–12 | `recommended` |
| `sl-pendulum` | ما الذي يؤثر فعلًا؟ | 11–12 | `none` |

## الإتقان

يُربط بهدف «المنهج العلمي».

| الحقل | القيمة |
|---|---|
| `score` | 1 **للتفسير** فقط — التوقع لا يُحسب |
| `max_score` | 1 |

الوصول إلى `independent` يتطلب تفسيرًا صحيحًا بلا مساعدة في 3 محاولات.

## إمكانية الوصول

- جدول النتائج **نصي** لا رسمًا بيانيًا فقط.
- المنزلق يقبل **أزرار +/−** كبديل للسحب.
- كل قيمة تُنطق عند التغيير.
- الرسوم المتحركة تحترم «تقليل الحركة».
- يعمل بالـD-pad.

## معايير القبول

- [ ] التوقع الخاطئ لا يُخصم ولا يُوصف بالفشل.
- [ ] لا تفسير قبل `min_trials_before_explain`.
- [ ] كل محاكاة مراجَعة علميًا وموثقة.
- [ ] أي تجربة منزلية لها `safety_notes` و`supervision_level = required`.
- [ ] الجدول متاح نصيًا.
- [ ] أزرار +/− بديلة للمنزلق.
