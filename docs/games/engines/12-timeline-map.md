# 12 — `timeline_map` · خط زمني وخريطة

## الهوية

| الحقل | القيمة |
|---|---|
| `engine_id` | `timeline_map` |
| المسار الأساسي | `junior` |
| التصنيف اللغوي | `translatable` |
| المدخلات | `drag`, `tap` |
| مؤقت | ❌ لا |
| `max_elements_on_screen` | 5 |
| هدف اللمس | 56dp |
| `supports_dpad` | ✅ |
| الهدف التعليمي | تسلسل تاريخي · موقع جغرافي · ربط الزمان بالمكان |

## القواعد

ثلاثة أنماط:

| النمط | الوصف |
|---|---|
| `timeline` | اسحب الحدث إلى موضعه على خط الزمن |
| `map` | اسحب العنصر إلى موقعه على الخريطة |
| `both` | ضع الحدث في زمنه **ومكانه** |

## شرط الفوز

كل العناصر داخل `tolerance_years` أو `tolerance_km`.

## سلوك الخطأ — توجيه اتجاهي

| المحاولة | السلوك |
|---:|---|
| 1 | سهم واتجاه: «أقدم من ذلك» أو «إلى الشرق» |
| 2 | تضييق المدى المعروض حول الجواب |
| 3 | إظهار حدث مرجعي معروف كمرساة |
| 4 | وضع العنصر تلقائيًا مع شرح تاريخي |

## المستويات الخمسة

| المستوى | النمط | العناصر | المدى | التسامح |
|---:|---|---:|---|---:|
| 1 | `timeline` | 3 | قرون متباعدة | ±100 سنة |
| 2 | `timeline` | 4 | 900 سنة | ±75 سنة |

## الأصول

- خريطة أساس **محيّدة سياسيًا** — بلا حدود متنازع عليها.
- صورة `4:3` لكل حدث.
- صوت لكل تسمية وشرح.
- **مراجعة تاريخية معتمدة إلزامية** لكل حزمة.

| البند | القاعدة |
|---|---|
| التخزين | **ميلاديًا دائمًا** |
| العرض | هجريًا أو ميلاديًا حسب اللغة والمنطقة |
| القيمة المعروضة | لا تُخزَّن كبيانات دائمة أبدًا |

## إمكانية الوصول

- خط الزمن **يُعكس** في RTL؛ الخريطة **لا تُعكس** أبدًا.
- بديل السحب: لمس العنصر ثم لمس الموضع، **مع أزرار تحريك دقيق**.
- كل موضع له وصف نصي («القرن الثامن الميلادي»).
- يعمل بالـD-pad.
