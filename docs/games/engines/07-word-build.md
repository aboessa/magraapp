# 07 — `word_build` · بناء الكلمة · حزمة مستقلة لكل لغة

## الهوية

| الحقل | القيمة |
|---|---|
| `engine_id` | `word_build` |
| المسار الأساسي | `kids` |
| التصنيف اللغوي | **`language_specific`** — يُؤلَّف لكل لغة ولا يُترجم |
| المدخلات | `drag`, `tap` |
| مؤقت | ❌ لا |
| `max_elements_on_screen` | 8 |
| هدف اللمس | 56dp |
| `supports_dpad` | ✅ |
| الهدف التعليمي | وعي صوتي · إملاء · مفردات |

## القواعد

تُنطق الكلمة وتُعرض صورتها، وتُعرض حروفها مبعثرة مع مشتّتات. يرتّب الطفل الحروف في خانات بعدد حروف الكلمة، **باتجاه كتابة اللغة**.

## شرط الفوز

الكلمة مكتملة صحيحة. محاولات غير محدودة.

## سلوك الخطأ

| المحاولة | السلوك |
|---:|---|
| 1 | الحرف يرتد + عبارة محاولة |
| 2 | **نطق الحرف التالي الصحيح** وتوهج خانته |
| 3 | إخفاء المشتّتات |
| 4 | وضع الحرف تلقائيًا مع نطق الكلمة كاملة |

## المستويات الخمسة

| المستوى | الحروف | المشتّتات | ملاحظة |
|---:|---:|---:|---|
| 1 | 2 | 0 | كلمة من حرفين |
| 2 | 3 | 1 | كلمة شائعة |
| 3 | 3 | 2 | حروف متشابهة الشكل |
| 4 | 4 | 2 | كلمة بأربعة حروف |
| 5 | 4–5 | 3 | حرف مشدّد أو مدّ |

## قواعد لغوية إلزامية

| اللغة | القواعد |
|---|---|
| **العربية** | الحرف يُعرض **بشكله الصحيح في الكلمة** (`form`)؛ «ق» في «قمر» تختلف شكلًا عن «ق» منفردة. تجاهل هذا يُعلّم شكلًا خاطئًا |
| **العربية** | الحرف يُنطق **بصوته** لا باسمه للمبتدئين: «قَ» لا «قاف»؛ ويُتاح الاسم للأكبر |
| **الإنجليزية/الفرنسية** | لا `form`، الاتجاه `ltr`، وتُضاف قواعد الحروف الصامتة |
| **الأردية** | اتجاه `rtl` مع أبجدية مختلفة عن العربية — **حزمة مستقلة تمامًا** |
| الكل | المشتّتات تُختار من حروف **قريبة صوتيًا أو شكليًا**، لا عشوائيًا |

## الأصول

- صورة `1:1` لكل كلمة.
- تسجيل الكلمة كاملة **ومقطّعة**.
- تسجيل صوت كل حرف **بكل أشكاله المستخدمة**.
- بطاقات حروف بخط عربي واضح للأطفال — **ترخيص الخط متحقق منه**.

## إمكانية الوصول

- **زر «اعرض الكلمة مكتوبة»** — يجعل اللعبة قابلة للعب لمن لا يسمع. **إلزامي**.
- بديل السحب: لمس الحرف ثم لمس الخانة.
- الخط قابل للتكبير حتى 2.0×.
- يعمل بالـD-pad.
