# 03 — `sort_bins` · تصنيف

## الهوية

| الحقل | القيمة |
|---|---|
| `engine_id` | `sort_bins` |
| المسار الأساسي | `preschool` (يمتد إلى `kids` و`junior`) |
| التصنيف اللغوي | `translatable` |
| المدخلات | `drag`, `tap` |
| مؤقت | ❌ لا |
| `max_elements_on_screen` | 8 عناصر + 3 سلات |
| هدف اللمس | 64dp |
| `supports_dpad` | ✅ |
| الهدف التعليمي | تصنيف بخصيصة · استنتاج قاعدة |

## القواعد

2–3 سلات، كل سلة مسمّاة بصورة **وصوت**. 4–8 عناصر. يسحب الطفل كل عنصر إلى سلته. العنصر المصنّف صحيحًا يستقر داخل السلة بصريًا.

## شرط الفوز

كل العناصر مصنّفة صحيحًا. لا مؤقت ولا حد محاولات.

## سلوك الخطأ

| المحاولة | السلوك |
|---:|---|
| 1 | ارتداد لطيف + عبارة محاولة |
| 2 | توهج السلة الصحيحة |
| 3 | إخفاء سلة خاطئة (تقليل الاختيار) |
| 4 | نقل تلقائي مع شرح: «التفاحة حمراء، فتذهب هنا.» |

## المستويات الخمسة

| المستوى | السلات | العناصر | معيار التصنيف |
|---:|---:|---:|---|
| 1 | 2 | 4 | لون واحد مقابل آخر |
| 2 | 2 | 6 | شكل |
| 3 | 3 | 6 | حجم: كبير/متوسط/صغير |
| 4 | 3 | 8 | خصيصتان معًا (لون + شكل) |
| 5 | 3 | 8 | قاعدة مجرّدة: يعيش في الماء / يطير / يزحف |

## الأصول

- 2–3 صور سلات `1:1`.
- 4–8 صور عناصر `1:1` شفافة.
- صوت لكل سلة وكل عنصر.
- صوت شرح لكل عنصر عند `explain_on_correct`.

## حزم الإطلاق الثلاث

|---|---|---|
| `sb-colors` | ألوان حولنا | 3–4 |
| `sb-shapes-size` | أشكال وأحجام | 4–5 |

## الإتقان

| الحقل | القيمة |
|---|---|
| `score` | العناصر الصحيحة من أول محاولة |
| `max_score` | عدد العناصر |

## إمكانية الوصول

- **بديل السحب إلزامي:** لمس العنصر ثم لمس السلة.
- السلة مميزة بـ**صورة + نص + صوت**، لا باللون وحده.
- يعمل بالـD-pad على TV.
