# 01 — `match_pairs` · مطابقة كبيرة

## الهوية

| الحقل | القيمة |
|---|---|
| `engine_id` | `match_pairs` |
| المسار الأساسي | `preschool` (يمتد إلى `kids`) |
| التصنيف اللغوي | `translatable` |
| المدخلات | `drag`, `tap` |
| مؤقت | ❌ لا يوجد |
| `max_elements_on_screen` | 6 |
| هدف اللمس | 72dp |
| `interaction_mode` | `tap` |
| `supports_dpad` | ✅ |
| الهدف التعليمي | تمييز بصري · مفردات · علاقة منطقية بسيطة |

## القواعد

تُعرض 2–3 **أهداف ثابتة** في الأعلى، و2–6 **عناصر متحركة** في الأسفل. يسحب الطفل العنصر إلى هدفه.

أنواع الربط المدعومة:

| `match_type` | مثال |
|---|---|
| `identical` | صورة تفاحة ← صورة تفاحة |
| `shadow` | أرنب ← ظل الأرنب |
| `relation` | سمكة ← البحر |
| `sound_image` | كلمة منطوقة «قطة» ← صورة القطة |
| `part_whole` | عجلة ← سيارة |

عند لمس أي عنصر يُنطق اسمه فورًا. عند لمس الهدف يُنطق اسمه أيضًا.

## شرط الفوز والخروج

- **فوز:** كل الأزواج صحيحة.
- **لا فشل.** المحاولات غير محدودة (`max_attempts = NULL`).
- الخروج متاح دائمًا ويحفظ المستوى الحالي.

## سلوك الخطأ وسلّم المساعدة

| المحاولة الفاشلة | السلوك |
|---:|---|
| 1 | العنصر يعود لمكانه بحركة لطيفة (200ms) + عبارة محاولة. **لا صوت سلبي** |
| 2 | يتوهج الهدف الصحيح بلون `Comet Cyan #00D6F5` نبضتين |
| 3 | تُخفى المشتّتات، ويبقى الزوج الصحيح فقط |
| 4 | العنصر ينتقل تلقائيًا لهدفه مع شرح صوتي |
| 5+ | اقتراح لعبة أسهل، **بلا وصف بالفشل** |

## المستويات الخمسة

| المستوى | الأهداف | العناصر | المشتّتات | نوع الربط | ملاحظة |
|---:|---:|---:|---:|---|---|
| 1 | 2 | 2 | 0 | `identical` | مختلف تمامًا في اللون والشكل |
| 2 | 3 | 3 | 0 | `identical` | ألوان مختلفة |
| 3 | 3 | 4 | 1 | `relation` | مشتّت واحد واضح |
| 4 | 3 | 5 | 2 | `shadow` | تشابه في اللون |
| 5 | 3 | 6 | 3 | `sound_image` | يعتمد على الصوت + بديل بصري |

## سكربت الصوت العربي

| المفتاح | النص | ملاحظة |
|---|---|---|
| `vo.intro` | «هيا نلعب معًا!» | مرة واحدة عند الفتح |
| `vo.instruction` | حسب `match_type` — انظر الجدول أدناه | |
| `vo.instruction_repeat` | نفس النص بسرعة أبطأ 15% | زر دائم |
| `vo.item_label.*` | «قطة» · «سمكة» · «طائر» | عند اللمس |
| `vo.correct` | من بنك التشجيع | كل 2–3 نجاحات لا كل نجاح |
| `vo.retry` | «جرّب مرة أخرى» | نبرة دافئة لا محبطة |
| `vo.hint` | «انظر إلى المكان الذي يعيش فيه.» | تلميح للقاعدة لا للجواب |
| `vo.level_complete` | «أكملت المستوى!» | + لحن 1.2s |
| `vo.game_complete` | «انتهينا! كان لعبًا جميلًا.» | |
| `vo.exit_confirm` | «نتوقف الآن؟» | |

### التعليمة لكل نوع ربط

| `match_type` | التعليمة |
|---|---|
| `identical` | «اسحب كل صورة إلى الصورة المثلها.» |
| `shadow` | «اسحب كل صورة إلى ظلها.» |
| `relation` | «اسحب كل حيوان إلى بيته.» |
| `sound_image` | «استمع، ثم اسحب الصورة الصحيحة.» |
| `part_whole` | «اسحب كل جزء إلى مكانه.» |

## الأصول المطلوبة لكل حزمة

- 3–6 صور أهداف `1:1` بخلفية شفافة.
- 4–9 صور عناصر `1:1` بخلفية شفافة.
- تسجيل صوتي لاسم كل عنصر وهدف.
- 10 مفاتيح صوتية إلزامية.
- غلاف اللعبة `1:1` من مجموعة الصور H.

## حزم الإطلاق الثلاث

| الحزمة | العنوان | الهدف | الفئة |
|---|---|---|---|
| `mp-animals-home` | أين يعيش؟ | ربط الحيوان ببيئته | 3–5 |
| `mp-colors-shapes` | مثلها تمامًا | تمييز اللون والشكل | 3–4 |
| `mp-story-echo` | ماذا رأيت في الحلقة؟ | فهم مرتبط بحلقة | 4–6 |

## الإتقان

يكتب إلى `objective_id` الخاص بالحزمة.

| الحقل | القيمة |
|---|---|
| `score` | الأزواج الصحيحة **من أول محاولة** |
| `max_score` | عدد الأزواج |

## إمكانية الوصول

- كل عنصر له وصف بديل لقارئ الشاشة.
- **بديل السحب إلزامي:** لمس العنصر ثم لمس الهدف.
- على TV: تحديد بالـD-pad ثم زر التأكيد.
- المشتّت **لا يُميَّز باللون وحده**.
