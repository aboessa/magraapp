# 04 — سياسة التشجيع والفشل

> هذا المستند هو **أهم مستند تربوي** في توثيق الألعاب. يُنفَّذ في **طبقة مشتركة مركزية**، لا داخل كل لعبة. لو نُفِّذ 12 مرة نشأت 12 سلوكًا مختلفًا وانكسرت السياسة.

## القواعد الحاسمة

| # | القاعدة | السبب |
|---:|---|---|
| 1 | **شجّع الجهد لا الذكاء** | «أنت ذكي جدًا» تجعل الطفل يخاف الفشل ويتجنب التحدي. «حاولت بتركيز» تبني المثابرة |
| 2 | **لا تكرر العبارة نفسها مرتين متتاليتين** | التكرار يُفقد التشجيع معناه |
| 3 | **لا مبالغة** | «رائع! مذهل! خارق!» عند مطابقة بطاقتين يُفقد المعنى قيمته |
| 4 | **لا مقارنة بأطفال آخرين، لا leaderboard، لا streaks ضاغطة** | تُنتج قلقًا وتنافسًا غير صحي |
| 5 | **لا تشجيع على السرعة** | لا مؤقت في أي محرك `preschool` |
| 6 | **الصمت مقبول ومطلوب** | شجّع كل 2–3 نجاحات لا كل نجاح |

## آلية الاختيار

```
اختر عبارة عشوائية من بنك المسار
  مع استبعاد آخر عبارتين استُخدمتا
  ومع تخطي التعليق إذا كان عدد النجاحات منذ آخر تعليق < 2
```

## بنك عبارات — `preschool` 3–5

**نجاح** (≤ 4 كلمات، منطوقة):

| العبارة |
|---|
| أحسنت! |
| نعم، صحيح! |
| جميل جدًا! |
| وجدتها! |
| هكذا تمامًا! |
| ممتاز! |
| يا سلام! |
| صحيح، أحسنت! |

**محاولة** — **لا تقل «خطأ» أبدًا**:

| العبارة |
|---|
| جرّب مرة أخرى |
| قريب جدًا! |
| هيا نجرب غيرها |
| لا بأس، حاول |
| انظر مرة أخرى |

**إكمال مستوى:** أكملت المستوى! · أنت رائع! · هيا للمستوى التالي!

**إكمال لعبة:** انتهينا! لعبنا بشكل جميل. · أحسنت! أكملت اللعبة كلها.

## بنك عبارات — `kids` 6–8

**نجاح:**

| العبارة |
|---|
| إجابة صحيحة، أحسنت! |
| تفكير ممتاز! |
| صحيح تمامًا! |
| لاحظت الفرق، جيد جدًا! |
| أحسنت، رتّبتها صح! |

**محاولة:**

| العبارة |
|---|
| ليست هذه، جرّب مرة أخرى |
| فكّر في اللون مرة أخرى |
| اقتربت! انظر للخطوة الأولى |
| حاول مرة أخرى، أنت تفهمها |

**إكمال:** أنجزت المستوى! · عمل منظم، أحسنت! · تقدّمت خطوة جيدة!

## بنك عبارات — `junior` 9–12

نبرة محترمة **بلا تصغير**. الروّاد يُنفَّرون من النبرة الطفولية، واستخدامها معهم يدفعهم لترك التطبيق.

**نجاح:**

| العبارة |
|---|
| استنتاج صحيح. |
| تحليل دقيق. |
| صحيح — لاحظت القاعدة. |
| حل فعّال، أحسنت. |
| تفكير منطقي واضح. |

**محاولة:**

| العبارة |
|---|
| ليست صحيحة. راجع العلاقة بين الصفين. |
| أعد النظر في المتغير الذي تغيّر. |
| قريب. تحقق من الخطوة الأخيرة. |
| جرّب فرضية أخرى؛ التجربة تسمح بذلك. |

**إكمال:** أكملت التحدي. · حللته بعدد خطوات جيد. · أتممت التجربة وفسّرتها.

## سياسة الفشل المتكرر

| المحاولات الفاشلة | ما يحدث |
|---:|---|
| 1 | عبارة محاولة، لا تغيير |
| 2 | تلميح تلقائي + إبراز بصري |
| 3 | **تبسيط المستوى**: تقليل العناصر أو إزالة المشتّتات |
| 4 | **عرض الحل** مع شرح صوتي، ثم متابعة عادية |
| 5+ | «نلعب شيئًا آخر؟» مع اقتراح لعبة أسهل — **بلا وصف بالفشل** |

### قواعد ملازمة

- الطفل **لا يُقفل خارج** أي محتوى بسبب الفشل، إطلاقًا.
- **لا رسالة «حاولت كثيرًا»** ولا عدّ أخطاء معروض للطفل.
- تقرير ولي الأمر يقول «يحتاج تدريبًا على التصنيف باللون» **لا** «فشل 5 مرات».
- بعد التبسيط، النجاح يُشجَّع **بشكل كامل** لا منقوص.
- استخدام الحل يضع `attempts.help_used = 1` فقط، ولا يمنع تقدم الطفل.

## المحركات المستثناة من التعليق

| المحرك | الاستثناء | السبب |
|---|---|---|
| `memory_flip` | **لا `vo.retry` إطلاقًا — صمت مقصود** | التعليق على كل قلب فاشل يفسد متعة اللعب |
| `rhythm_tap` | لا `vo.correct` ولا `vo.retry` | الموسيقى نفسها هي التغذية الراجعة |
| `sim_lab` | التوقع الخاطئ ليس فشلًا | التوقع الخاطئ جزء من المنهج العلمي |
| `trace_color` (تلوين) | لا شرط نجاح إطلاقًا | التلوين تعبير حر |

## المكافآت

| مسموح | ممنوع |
|---|---|
| نجمة أو ملصق هادئ عند إكمال اللعبة | عملة داخلية |
| مجموعة «مجموعتي» تُراكم الملصقات | شراء داخل اللعبة |
| تنويع المكافآت بصريًا | صناديق عشوائية |
| | إعلانات |
| | مكافأة يومية تعاقب الغياب |
| | خسارة مكافأة مكتسبة |

**قاعدة:** المكافآت المكتسبة **لا تُفقد أبدًا**، تحت أي شرط.

## متطلبات التنفيذ

الطبقة المشتركة تُعرّض هذه الواجهة، وكل محرك يستدعيها فقط:

```dart
abstract class FeedbackService {
  void onCorrect({required AgeTrack track});
  void onIncorrect({required AgeTrack track, required int failedAttempts});
  void onLevelComplete({required AgeTrack track});
  void onGameComplete({required AgeTrack track});
  HelpAction resolveHelp({required int failedAttempts, required HelpSystem config});
}

enum HelpAction { none, hint, simplify, solution, suggestOther }
```

## معايير القبول

- [ ] لا محرك يحتوي منطق تشجيع خاصًا به.
- [ ] لا تكرار لعبارة مرتين متتاليتين.
- [ ] التعليق يظهر كل 2–3 نجاحات لا كل نجاح.
- [ ] سلّم الفشل الخمسي مطبَّق في كل محرك.
- [ ] لا قفل محتوى بسبب الفشل.
- [ ] لا عدّ أخطاء ظاهر للطفل.
- [ ] تقارير ولي الأمر بلغة وصفية لا عددية سلبية.
- [ ] بنوك العبارات الثلاثة كاملة في ملفات الترجمة بمفاتيح دلالية.
