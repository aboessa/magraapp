# سكربت إعلان «مجرة» — موشن جرافيك

- المدة: 36–40 ثانية تقريبًا (تتحدد تلقائيًا من طول الفويس أوفر)
- المقاس: عمودي 1080×1920 (Reels / TikTok / Shorts / Stories)
- الصوت: راوية عربية فصحى دافئة (Gemini TTS، صوت `Kore`)
- الخط: Readex Pro (خط التطبيق نفسه)، والألوان من `brandcolor.md`
- مصدر النص الفعلي للفويس: `src/script.json`. أي تعديل هناك يغيّر الصوت والتوقيت معًا.

| # | المشهد | الفويس أوفر | على الشاشة | الحركة |

## اللي اتأكدت منه في الكود قبل ما أكتب الادعاءات

- التنزيل والمشاهدة بدون إنترنت: `app_main/lib/features/downloads/` (التنزيل مربوط بالباقة، عشان كده الصياغة «تنزيل للمشاهدة» ومفيش وعد إنه مجاني).
- الرقابة الأبوية وتقارير النشاط: `parent_dashboard_page.dart` (`ParentalControlsSection` و`_ActivityReports`).
- الفئة العمرية 3–12: `brandcolor.md` والمسارات preschool وkids وjunior.
- مفيش أي ادعاء عن السعر، ولا مقارنة بمنافسين بالاسم.

## التشغيل

```powershell
npm install
npm run assets        # ينسخ الشعار والخط والكواكب والبوسترات وصور الشخصيات إلى public/
npm run voiceover     # يولّد الفويس بـ Gemini TTS (المفتاح GEMINI_API_KEY من .env.local)، وأضف --force لإعادة التوليد
node scripts/check-voiceover.mjs   # يفرّغ الصوت نصيًا ويقارنه بالسكربت
npm run studio        # معاينة وتعديل تفاعلي
npm run render:draft  # مسودة من غير مشهد الشخصيات
npm run render        # النسخة النهائية (بعد اعتماد الـ Character Sheet)
```

## نسخة 30 ثانية (`MajarraPromo30`)

نفس المشاهد الثمانية ونفس الشخصيات المعتمدة، لكن بنص أقصر في `src/script-30.json` وفويس منفصل في `public/vo30/` وتوقيتات في `src/voiceover-30.json`. النسخة الكاملة ما بتتأثرش.

```powershell
npm run voiceover:30                                   # 8 طلبات TTS (الحد المجاني 10 في اليوم)
node scripts/check-voiceover.mjs --script src/script-30.json
npm run render:30                                      # out/majarra-promo-30s.mp4
```

بعد توليد الصوت لازم تتظبط `beats` في `script-30.json` على أوقات الكلمات الفعلية.

## نسخة مصري 30 ثانية (`MajarraPromoEgy30`)

فكرة واستايل مختلفين: ستايل «Pop Sticker» (ألوان فلات، حدود Ink سميكة، halftone، كلمات بتتختم على الشاشة، هزّة كاميرا، wipes) على بيت 120 BPM، وكل قطع بيقع على الـkick. الفويس: `Zephyr` بعامية مصرية قاهرية (اتأكد بالتفريغ النصي). الشخصيات الوحيدة الظاهرة هي بوسترات المكتبة الموجودة بالفعل؛ مفيش توليد صور جديدة.

| # | الفويس | الحركة |
|---|---|---|
| 1 | ابنك مش راضي يسيب الموبايل؟ | موبايل بيخبط من تحت، الكلمات بتتختم، والموبايل بيتشد ويرجع |
| 2 | خلاص.. سيبُه! بس بدل الفيديوهات اللي ملهاش لازمة.. | الخلفية بتبهت للرمادي، سكرول رمادي بيسرّع مع glitch، وبعدين X كبيرة |
| 3 | خلّيه يدخل مَجَرّة! | iris wipe، الموسيقى بتقف نص بيت، والشعار بيخبط مع squash وحلقات وكونفيتي |
| 4 | حواديت.. أرقام.. علوم.. وقيم! لكل سن، من تلاتة لاتناشر سنة. | whip لكل كلمة ببوستر حقيقي، بعدين كولاج 2×2 وبادج «من ٣ لحد ١٢ سنة» |
| 5 | ومن غير ولا إعلان.. وإنت متابع كل حاجة بنفسك. | عداد إعلانات من 99 لـ 0، شريط «ولا إعلان!»، وكارت «لوحة الأهل» |
| 6 | مَجَرّة.. وقت الشاشة بقى وقت مفيد. نزّلها دلوقتي! | شعار، marker على «مفيد»، شريط بوسترات مايل، وزرار بيتداس على البيت |

```powershell
npm run egy:audio        # البيت + SFX (FFmpeg فقط، من غير مكتبات صوت)
npm run egy:voiceover    # 6 طلبات TTS + كشف بدايات الجمل
node scripts/check-voiceover.mjs --script src/egy/script-egy.json
npm run render:egy       # out/majarra-promo-egy-30s.mp4
```

النص والتوقيتات في `src/egy/script-egy.json` (`beats` بالثواني من بداية كل جملة)، والكود في `src/egy/`.
